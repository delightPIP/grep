# ARC-003 폴더는 따로 두지 않고, 한 단계짜리 묶음이 폴더 역할을 한다
- 상태: 확정
- 적용 범위: 모든 플랫폼의 `묶음`·`넘기기` 명령과 서버의 묶음 API. 기능은 F12(P1)

> **요약** 자료를 모아 두는 단위는 묶음 하나뿐이다. 묶음은 하위 묶음이 없는 한 단계이고, 자료 하나가 여러 묶음에 들어갈 수 있다. 묶음 목록 보기, 묶음 안 자료 보기, 넣기, 빼기, 묶음 지우기를 할 수 있다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 묶음 | 사용자가 이름을 붙여 자료를 모아 둔 것. 폴더 역할을 하고 `넘기기 <이름>`으로 한 번에 넘긴다 |
| 선택 | `고르기`로 고른 자료들. 묶음에 넣을 대상이 된다 |

## 규칙

1. 폴더는 두지 않는다. 묶음 안에 묶음을 둘 수 없다.
2. 자료 하나는 묶음 여러 개에 들어갈 수 있고, 어느 묶음에도 없어도 된다.
3. `묶음`만 치면, 클라이언트는 묶음 목록(이름, 자료 수)을 최근에 바뀐 순서로 보여 준다.
4. 선택이 있을 때 `묶음 <이름>`을 치면, 서버는 선택한 자료를 그 묶음에 넣는다. 그 이름의 묶음이 없으면 새로 만든다. 넣은 뒤 선택은 비운다.
5. 선택이 없을 때 `묶음 <이름>`을 치면, 클라이언트는 그 묶음 안 자료를 자료 번호가 큰 순서(최근 저장 순)로 보여 준다.
6. 이미 묶음에 있는 자료를 다시 넣으면, 서버는 한 번만 둔다. 오류로 다루지 않는다.
7. `묶음 <이름> 빼기 <번호...>`를 치면, 서버는 그 자료를 묶음에서만 뺀다. 자료는 지우지 않는다.
8. `묶음 <이름> 지우기`를 치면, 클라이언트는 확인을 받은 뒤 묶음만 지운다. 안의 자료는 지우지 않는다.
9. 묶음 안 자료를 모두 빼도 묶음은 0건으로 남는다.
10. 자료를 지우면, 그 자료는 모든 묶음에서 빠진다. `넘기기 <이름>`을 하면 지운 자료 수를 알린다.
11. 묶음 이름은 한 사용자 안에서 유일하다. 영문은 대소문자를 가리지 않고 같은 이름으로 본다.
12. 묶음 이름 규칙에 맞지 않으면, 클라이언트는 묶음을 만들지 않고 규칙을 알린다.
13. 묶음 이름 바꾸기는 두지 않는다.

## 값

| 항목 | 값 | 경계 |
| :--- | :--- | :--- |
| 묶음 단계 | 1단계 | 하위 묶음 없음 |
| 이름 길이 | 1~20자 | 21자 이상은 거부 |
| 이름 글자 | 한글, 영문, 숫자, `-`, `_` | 띄어쓰기와 그 밖의 기호는 거부 |
| 금지 이름 | 숫자만으로 된 이름, `#`으로 시작하는 이름, `빼기`·`지우기` | 자료 번호(ARC-001), 태그(ARC-002), 하위 명령과 헷갈리지 않게 |
| 묶음 수, 묶음당 자료 수 | 상한 없음 | 값은 [열린 질문](open-questions.md) |

## 사용자 문구

| 상황 | 제목 | 본문 | 버튼 |
| :--- | :--- | :--- | :--- |
| 묶음 목록 | 없음 | `N개 묶음` 뒤에 묶음마다 `<이름>  N건`. 없으면 `· 묶음 0개  → 고르기 <번호> · 묶음 <이름>` | 없음 |
| 넣기 | 없음 | `✓ 묶음 <이름>: N건` 뒤에 `→ 다음부터: 넘기기 <이름>` | 없음 |
| 이미 들어 있는 자료 포함 | 없음 | `✓ 묶음 <이름>: N건 (이미 있음 M건)` | 없음 |
| 묶음 안 자료 보기 | 없음 | `묶음 <이름>  N건` 뒤에 자료 목록 | 없음 |
| 없는 묶음 보기 | 없음 | `✗ 없는 묶음: <이름>  → 묶음` | 없음 |
| 빼기 | 없음 | `✓ 뺌  묶음 <이름>: N건 남음` | 없음 |
| 묶음에 없는 번호 빼기 | 없음 | `✗ 묶음에 없음: <번호>` | 없음 |
| 지우기 확인 | 없음 | `삭제? 묶음 <이름> (자료 N건은 남음)` | `1 취소 · 2 삭제` |
| 지움 | 없음 | `✓ 삭제됨  묶음 <이름>` | 없음 |
| 이름 규칙 위반 | 없음 | `✗ 묶음 이름: 띄어쓰기 없이 1~20자 (한글·영문·숫자·-·_)` | 없음 |
| 금지 이름 | 없음 | `✗ 묶음 이름: 숫자만 · #시작 · 빼기 · 지우기 불가` | 없음 |
| 넘길 때 지운 자료 있음 | 없음 | `! 빠진 자료 N건 (삭제됨)` | 없음 |

## 근거

- PO 결정(2026-11-26): 폴더를 따로 만들지 않고 묶음이 폴더 역할을 한다. 한 단계. 목록·보기·넣기·빼기·지우기를 넣고 이름 바꾸기는 나중. 이름은 띄어쓰기 없이 1~20자
- 기획서 F12, "하지 않는 것"(태그·폴더 관리 화면을 중심에 두지 않음), 명령어 설명서 3절 `묶음`, 백엔드 설계(묶음과 자료의 N:M)
- STATE E-11, E-40(사람들은 폴더 탐색을 선호한다) — 묶음 보기를 넣은 이유
- 구현: 아직 없음

## 검증 방법

| 종류 | 확인할 것 |
| :--- | :--- |
| 자동 테스트 | 같은 자료를 두 번 넣어도 한 번만 있는지, 두 기기에서 동시에 넣어도 같은지 |
| 자동 테스트 | 이름 규칙: 0자, 20자, 21자, 띄어쓰기, 숫자만, `#` 시작, 대소문자만 다른 이름 |
| 자동 테스트 | 묶음 지우기 뒤 자료가 남는지, 자료 지우기 뒤 묶음에서 빠지고 넘길 때 빠진 건수가 나오는지 |
