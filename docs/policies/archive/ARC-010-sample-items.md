# ARC-010 첫 화면의 샘플 8건은 실제 자료로 저장하고 버리기로 치운다
- 상태: 검토 중 (개발자 확인 대기)
- 적용 범위: 자료 0건인 첫 화면(모든 플랫폼), 샘플 자료의 번호(ARC-001)·버리기(ARC-008)

> **요약** 자료가 0건일 때 첫 화면의 `→ 샘플 8건으로 해 보기`를 누르면, 서버는 샘플 8건을 그 사용자의 자료로 저장하고 1~8번을 준다. 치울 때는 새 명령 없이 `버리기 1-8`을 쓴다.

## 규칙

1. 샘플 안내 `→ 샘플 8건으로 해 보기`는 자료가 0건일 때만 보인다. 휴지통 자료는 건수에 넣지 않는다.
2. 누르면, 서버는 샘플 8건을 그 사용자의 자료로 저장한다. 번호는 저장 순서대로 1~8이다(ARC-001).
3. 8건은 한꺼번에 저장한다. 하나라도 실패하면 아무것도 저장하지 않고 실패를 알린다.
4. 저장이 끝나면, 클라이언트는 완료 줄과 치우는 방법을 한 줄씩 보여 주고 `최근`과 같은 목록을 띄운다.
5. 샘플은 일반 자료와 똑같이 `찾기`·`고르기`·`넘기기`·묶음·`고치기`·`버리기`를 쓸 수 있다. 샘플 표시는 따로 두지 않는다.
6. 치울 때는 `버리기 1-8`을 쓴다. `버리기`는 `a-b` 꼴의 번호 범위를 받는다. 버린 샘플은 다른 자료처럼 휴지통으로 간다(ARC-008).
7. 같은 안내를 두 번 눌러도 한 번만 저장한다.

## 값

| 항목 | 값 | 경계 |
| :--- | :--- | :--- |
| 샘플 건수 | 8건 | 마케터 캠페인 이야기 7건 + 그렙 사용법 1건 |
| 받는 번호 | 1~8 | 자료 0건에서만 저장하므로 늘 1번부터 |
| 번호 범위 꼴 | `a-b` | a ≤ b. 없는 번호가 섞이면 명령 전체를 실행하지 않는다(ARC-001 규칙 10) |
