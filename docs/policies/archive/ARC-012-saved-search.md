# ARC-012 저장한 찾기는 `찾아두기 <검색어>`로 만들고 보고 지우며, 이름은 검색어 그대로다
- 상태: 검토 중 (개발자 확인 대기)
- 구현 시점: 발표 뒤. 데모 범위 밖이다(2026-11-26 PO 결정, STATE 12절)
- 적용 범위: 모든 플랫폼의 터미널 `찾아두기` 명령과 보관함의 저장한 찾기(ARC-007)

> **요약** `찾아두기 텀블러 캠페인`을 치면 그 검색어를 저장하고 지금 맞는 자료를 보여 준다. 이미 저장한 검색어면 저장 없이 결과만 보여 준다. 저장한 찾기의 이름은 검색어 그대로이고, 모이는 자료는 언제나 `찾기 <검색어>`의 결과와 같다. 보관함에서는 찾기 칸 결과 위 `이 찾기 저장` 버튼으로 같은 일을 한다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 저장한 찾기 | 사용자가 저장한 검색어. 맞는 자료가 저절로 모인다(ARC-007) |
| 검색어 | `찾기` 뒤에 치는 낱말들. `#태그`를 포함할 수 있다(ARC-002) |

## 규칙

1. `찾아두기 <검색어>`(영문 `gather`)를 치면, 서버는 그 검색어를 저장한 찾기로 저장하고 클라이언트는 `찾기 <검색어>`와 같은 결과를 보여 준다.
2. 같은 검색어가 이미 저장되어 있으면, 새로 만들지 않고 결과만 보여 준다. 같은지는 앞뒤 공백을 지우고 낱말 사이 공백을 하나로 줄인 뒤 비교한다. 낱말 차례가 다르면 다른 검색어다.
3. 저장한 찾기의 이름은 검색어 그대로다. 따로 이름을 붙이거나 바꾸지 않는다.
4. 검색어의 마지막 낱말이 시점(`지난주`, `3주전` 등, 명령어 설명서 3절)이면 저장하지 않고 실패로 알린다. 날마다 뜻이 바뀌어 모이는 자료가 예상과 달라지기 때문이다. 시점 낱말 자체를 찾으려면 따옴표로 감싼다(`찾아두기 "지난달"`).
5. 결과가 0건이어도 저장한다. 맞는 자료가 나중에 저장되면 모인다.
6. `찾아두기`만 치면, 클라이언트는 저장한 찾기 목록을 만든 순서 최신부터 `<검색어>  N건`으로 보여 준다. 0건인 것도 보여 준다.
7. `찾아두기 <검색어> 지우기`를 치면, 클라이언트는 확인을 받은 뒤 그 저장한 찾기를 지운다. 자료는 지우지 않는다. 확인 방식은 명령어 설명서 6절(같은 명령 다시 입력이면 실행)을 따른다.
8. 결과의 순서, 건수 표시, `더 보기`, 이어 쓰기(`찾아두기 <검색어> | 넘기기`, 5건 초과 확인)는 `찾기`와 같다.
9. `찾기 <검색어>` 결과의 다음 명령 칩에는 `찾아두기 <검색어>`를 둔다. 그 검색어가 이미 저장되어 있으면 두지 않는다.
10. 보관함에서 찾기 칸으로 찾으면, 결과 머리줄에 `이 찾기 저장` 버튼을 둔다. 누르면 `찾아두기 <검색어>`가 실행되고 터미널 기록에 남는다(ARC-011 규칙 10과 같은 방식). 이미 저장된 검색어면 버튼 자리에 `저장한 찾기`라고만 쓴다.
11. 보관함에서 저장한 찾기 하나를 열면, 머리줄에 `지우기` 버튼을 둔다. 누르면 규칙 7의 확인을 거친다.
12. 보관함의 저장한 찾기 구역에는 0건인 것을 보여 주지 않는다(ARC-007 규칙 7). 터미널 목록(규칙 6)에는 보여 준다.

## 검증 방법

| 종류 | 확인할 것 |
| :--- | :--- |
| 자동 테스트 | 같은 검색어(공백만 다름)를 두 번 저장하면 하나만 남는지, 낱말 차례가 다르면 둘이 되는지 |
| 자동 테스트 | 저장한 찾기의 결과가 같은 검색어의 `찾기` 결과와 같은지 |
| 자동 테스트 | 시점으로 끝나는 검색어는 저장되지 않고, 따옴표로 감싼 시점 낱말은 저장되는지 |
| 자동 테스트 | 지우기 뒤 자료는 남는지 |
| 리뷰 | 보관함 시안에 저장한 찾기 이름 바꾸기 컨트롤이 없는지 |

## 비고

- 저장한 찾기를 묶음처럼 `넘기기 <검색어>`로 넘기는 것은 두지 않는다. `넘기기 <이름>`은 묶음 이름만 받는다. 저장한 찾기는 `찾아두기 <검색어> | 넘기기`로 넘긴다.
- 새 자료가 저장한 찾기에 모였을 때 알려 주는 기능은 두지 않는다(탭 배지 없음, MOB-001 규칙 9).
