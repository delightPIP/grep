# ARC-006 서버는 공개 웹 페이지만 열어 본문을 가져오고, 로그인·유료벽·접근 제한을 우회하지 않는다
- 상태: 확정
- 적용 범위: 서버가 저장된 링크의 본문을 가져오는 모든 경우(저장 직후 처리, 북마크 가져오기 뒤 처리)

> **요약** 서버는 누구나 로그인 없이 열 수 있는 http·https 페이지만 가져온다. 로그인이나 구독이 필요하거나 접근을 막은 페이지, 내부망 주소는 열지 않고 링크와 제목만 저장한다. 가져온 본문은 저장한 때의 사본이며 자동으로 다시 가져오지 않는다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 공개 페이지 | 로그인, 구독, 결제, 사람 확인(CAPTCHA) 없이 누구나 열 수 있는 http·https 페이지 |
| 열지 않는 주소 | 사설망·로컬·클라우드 관리용 주소, 그런 주소로 넘어가는 리디렉션, 주소 안에 아이디·비밀번호가 든 링크 |

## 규칙

> **주의** 서버가 사용자가 넣은 주소를 대신 연다. 내부망 주소를 열면 서버의 비밀 키가 새어 나갈 수 있다(SSRF).

1. 서버는 공개 페이지만 가져온다.
2. 서버는 사용자의 쿠키, 로그인 정보, 다른 서비스의 토큰을 보내지 않는다.
3. 페이지가 로그인·구독·사람 확인을 요구하거나 접근을 거부하면, 서버는 우회하지 않고 `blocked`로 둔다(ARC-005).
4. 열지 않는 주소면, 서버는 요청을 보내지 않고 링크만 저장한다. 리디렉션을 따라갈 때마다 다시 확인한다.
5. 가져온 본문은 저장한 때의 사본이다. 원래 페이지가 바뀌어도 자동으로 다시 가져오지 않는다.
6. 같은 링크를 다시 저장해도(COM-001) 본문을 다시 가져오지 않는다.
7. 본문을 못 가져와도 사용자가 함께 붙여 넣은 글이나 스크린샷은 그대로 저장한다.

## 값

| 항목 | 값 | 경계 |
| :--- | :--- | :--- |
| 허용 스킴 | `http`, `https` | 그 밖의 스킴은 COM-001대로 글로 저장 |
| 응답 시간·크기 상한, 리디렉션 횟수, 막을 주소 대역 | 연결 5초, 응답 10초, 본문 2MB, 리디렉션 5번. 사설(10/8·172.16/12·192.168/16)·루프백·링크 로컬(169.254/16, 클라우드 관리 주소 포함)·CGNAT(100.64/10)·IPv6 ULA·예약 대역 | 2MB를 넘으면 앞부분만 쓰고 `(본문 일부만 가져옴)`. 401은 로그인 필요, 그 밖의 4xx는 접근 거부. 검사한 IP로 직접 연결하지는 않는다(DNS 재바인딩, 공개 배포 전 보완)(개발자 결정 2026-11-27, #59) |

## 근거

- PO 결정(2026-11-26): 외부 전문가 검토 3건이 모두 지적한 "서버가 여는 링크의 범위"를 발표 전에 확정. 보안 값은 개발자 판단
- 백엔드 설계 3절 10축(SSRF 차단, 크기·시간 상한), 기획서 10절(로그인이 필요한 페이지), ARC-005
- 구현: `server/src/main/kotlin/com/unwrap/grep/features/processing/adapters/http/HttpLinkFetcher.kt`, `server/src/main/kotlin/com/unwrap/grep/features/processing/domain/AddressGuard.kt`(#59)

## 검증 방법

| 종류 | 확인할 것 |
| :--- | :--- |
| 자동 테스트 | `127.0.0.1`, 사설망, 클라우드 관리 주소, 그쪽으로 리디렉션되는 공개 주소를 넣으면 요청이 나가지 않는지 |
| 자동 테스트 | 401·403·로그인 페이지 응답이 `blocked`가 되는지 |
| 자동 테스트 | 서버의 본문 요청에 쿠키·인증 헤더가 없는지 |

## 비고

- robots.txt를 따를지는 정하지 않았다. 그렙은 사용자가 고른 링크 하나를 여는 것이라 크롤링과 성격이 다르지만, 전문가 의견이 갈려 [열린 질문](open-questions.md)에 둔다.
- 가져온 본문을 얼마나 오래 보관할지, 저작권 신고를 어떻게 받을지는 공개 출시 전에 정한다([공통 열린 질문](../common/open-questions.md)).
