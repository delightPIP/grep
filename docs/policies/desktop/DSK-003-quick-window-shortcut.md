# DSK-003 빠른 창은 두더지를 누르거나 전역 단축키로 열고 닫는다
- 상태: 검토 중 (개발자 확인 대기)
- 적용 범위: 데스크톱 앱

> **요약** 두더지를 누르거나 `Ctrl+Shift+G`를 누르면 웹과 같은 터미널 빠른 창이 두더지 위에 열린다. 단축키를 등록하지 못하면 한 번 알리고 설정에서 바꾸게 한다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 빠른 창 | 두더지 위에 뜨는 작은 터미널 창. 웹과 같은 화면이다 |
| 전역 단축키 | 그렙이 앞에 없어도 동작하는 단축키. Tauri 플러그인으로 등록한다(ADR-WEB-007) |

## 규칙

1. 두더지를 누르거나 단축키를 누르면 빠른 창이 열리고, 다시 누르면 닫힌다.
2. 빠른 창은 웹과 같은 터미널 화면이고, 두더지 위에 뜬다. 열리면 입력줄에 초점이 간다.
3. `Esc`를 누르거나 창 밖을 누르면 빠른 창이 닫힌다. 치던 글자는 다음에 열 때까지 남긴다.
4. 단축키를 등록하지 못하면(다른 앱이 쓰는 중), 앱은 트레이 알림을 한 번 보여 주고 설정에서 바꾸게 한다. 두더지 누르기로는 계속 열 수 있다.
5. 사용자는 설정에서 단축키를 바꿀 수 있다.
6. 두더지를 숨긴 동안(DSK-001) 단축키를 누르면, 빠른 창은 두더지의 기본 자리 위에 뜬다.
7. 로그인하지 않았으면, 빠른 창에 로그인 안내를 보여 준다.
8. 로그인 안내에서 Google·GitHub를 누르면 브라우저에서 로그인하고 끝나면 빠른 창으로 돌아온다. 돌아오면 로그인한 계정을 한 줄로 알린다.
