# DSK-001 데스크톱 두더지는 화면 오른쪽 아래에 상주하고, 사용자가 숨기거나 끌 수 있다
- 상태: 검토 중 (개발자 확인 대기)
- 적용 범위: 데스크톱 앱(Windows. ADR-WEB-007의 Tauri 앱). 웹과 모바일에는 적용하지 않는다

> **요약** 앱이 켜지면 두더지가 작업 표시줄 위 오른쪽 아래에 항상 위로 뜨고, 전체 화면 앱이 앞에 있으면 숨는다. 트레이에서 1시간 숨기기와 종료를 할 수 있고, 컴퓨터를 켤 때 자동으로 시작하는 것이 기본이다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 두더지 | 화면 위에 상주하는 그렙 마스코트와 그 아래 땅굴 띠. 디자인 시스템 `Burrow` |
| 기본 자리 | 주 모니터의 작업 표시줄 위 오른쪽 아래, 가장자리에서 24px 떨어진 곳 |
| 트레이 아이콘 | 작업 표시줄 알림 영역의 두더지 `mark` 16px 아이콘 |

## 규칙

1. 앱이 켜지면, 두더지는 기본 자리에 뜬다.
2. 두더지는 항상 다른 창 위에 뜬다.
3. 전체 화면 앱(발표, 영상, 게임)이 앞에 있으면 두더지는 숨고, 끝나면 다시 뜬다.
4. 사용자는 두더지를 끌어 옮길 수 있다. 놓으면 가장 가까운 화면 가장자리에 붙고, 다음 실행 때도 그 자리에 뜬다.
5. 기억한 자리가 화면 밖이면(모니터를 뺀 경우), 두더지는 기본 자리에 뜬다.
6. 트레이 아이콘은 앱이 켜져 있는 동안 늘 있다. 우클릭 메뉴는 `1시간 숨기기 · 다시 보이기 · 설정 · 종료`다.
7. `1시간 숨기기`를 누르면 두더지는 숨고, 1시간 뒤 저절로 다시 뜬다. 숨긴 동안에도 단축키로 빠른 창을 열 수 있다(DSK-003).
8. 컴퓨터를 켤 때 자동으로 시작하는 것이 기본이다. 처음 설치 화면에 `컴퓨터 켤 때 시작`을 켜진 체크로 보여 주고, 설정에서 끌 수 있다.
9. 마우스를 올리면, 자료 수, 선택 수, 단축키를 한 장으로 보여 준다.
10. 두더지는 말하지 않는다. 글은 로그 카드와 빠른 창에만 쓴다.
