# DSK-002 데스크톱 두더지에 끌어다 놓으면 묻지 않고 저장한다
- 상태: 확정
- 적용 범위: 데스크톱 앱의 두더지와 땅굴 띠 영역

> **요약** 파일, 링크, 글을 두더지에 놓으면 분류를 묻지 않고 항목마다 저장하고, 결과를 두더지 옆 로그 카드 한 장으로 보여 준다. 받는 형식은 서버가 정하고, 받지 않는 항목은 저장하지 않고 알린다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 놓을 영역 | 두더지와 땅굴 띠를 둘러싼 점선 영역. 끌어 오는 동안만 보인다 |
| 로그 카드 | 두더지 옆에 뜨는 저장 결과 카드. 디자인 시스템 `Line`·`Hint`로 쓴다 |
| 받는 형식 | 서버의 형식 검증이 받는 파일 형식과 크기. 서버가 앱에 목록을 알려 준다 |

## 규칙

1. 파일, 링크, 글을 두더지 위로 끌어 오면, 앱은 놓을 영역과 `놓으면 저장`을 보여 주고 두더지는 만세를 한다.
2. 끌어 온 것이 모두 받는 형식이 아니면, 두더지는 만세 대신 고개를 흔들고 앱은 `받지 않는 형식`을 보여 준다.
3. 놓으면, 앱은 분류를 묻지 않고 항목마다 저장한다(F1).
4. 받는 형식과 크기는 서버의 형식 검증이 정한다(ADR-0001). 앱은 서버가 알려 준 목록으로 미리 거른다.
5. 받는 형식이 아닌 항목은 저장하지 않고 ✗ 줄로 알린다. 나머지 항목은 저장한다.
6. 이미 저장한 자료면, COM-001을 따라 새로 만들지 않고 `이미 저장됨` 줄을 보여 준다.
7. 결과는 두더지 옆 로그 카드 한 장으로 보여 준다. 카드는 3초 뒤 닫히고, 마우스를 올리면 멈춘다. 누르면 빠른 창을 열고 그 자료를 보여 준다.
8. ✗ 줄이 하나라도 있는 카드는 저절로 닫지 않는다.
9. 연결이 없으면, 앱은 저장하지 않고 `✗ 저장 못 함: 연결 없음`을 보여 준다. 원본 파일은 사용자의 컴퓨터에 그대로 있다.
10. 저장 중에 또 놓으면, 앱은 각각 따로 처리한다. 같은 항목이 두 번 가도 서버는 멱등성 키로 한 건으로 처리한다.

## 값

| 항목 | 값 | 경계 |
| :--- | :--- | :--- |
| 로그 카드 표시 시간 | 3초 | ✗ 줄이 있으면 닫기를 누를 때까지 |
| 파일 형식과 크기 | 서버가 정함 | 크기 상한은 공통 영역 열린 질문(임시 20MB)을 따른다 |
| 한 번에 놓는 항목 수 | 정하지 않음 | 데스크톱 영역 열린 질문 |

## 검증 방법

| 종류 | 확인할 것 |
| :--- | :--- |
| 수동 테스트 | PDF·이미지·링크·글을 놓으면 저장되고 카드가 3초 뒤 닫힘. .zip만 끌어 오면 고개를 흔듦. .zip과 PDF를 함께 놓으면 PDF만 저장되고 카드가 남음. 연결을 끊고 놓으면 저장되지 않고 알림. 같은 파일을 두 번 놓으면 이미 저장됨 |
| 자동 테스트 | 데스크톱 앱 테스트가 생기면 `Scripts/check-policy-acceptance.sh`의 DSK-002 규칙이 로그 카드 3초를 어설션하는지 검사 |

## 비고

- 데스크톱 앱은 아직 PRD 기능 목록에 없다. 범위에 들어가면 이 정책을 따른다.
- 끌어 오는 중의 안내 문구 `링크 · 글 · 이미지 · PDF`는 서버가 알려 준 받는 형식에 맞춰 바뀐다.
