# MOB-001 모바일 화면은 하단 탭 세 개(터미널 · 보관함 · 설정)로 오가고, 설정은 탭으로 둔다
- 상태: 확정
- 적용 범위: iOS·Android 앱과 폭 600px 미만 웹(모바일 웹·설치형 PWA). 더 넓은 웹과 데스크톱 앱의 화면 배치는 이 정책 밖이다

> **요약** 좁은 화면에서는 맨 아래 탭 세 개로 터미널, 보관함, 설정을 오간다. 앱은 늘 터미널 탭에서 시작하고, 키보드·시트·고르기 중에는 탭바를 숨긴다. 탭은 화면 이동에만 쓰고 배지는 달지 않는다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 탭바 | 화면 맨 아래에서 탭 세 개를 보여 주는 줄 |
| 터미널 탭 | 저장·찾기·고르기·넘기기를 하는 로그 화면. 모바일 시안 M1~M5가 모두 이 탭이다 |
| 보관함 탭 | 자료를 명령 없이 훑어보는 화면(ARC-007) |
| 설정 탭 | 계정, 기기, AI 도구 연결처럼 자주 바꾸지 않는 값을 두는 화면 |
| 선택 | `고르기`나 보관함에서 고른 자료들(ARC-003) |

## 규칙

1. 탭은 왼쪽부터 `터미널`, `보관함`, `설정` 세 개다. 설정은 머리줄 아이콘이 아니라 탭으로 둔다.
2. 탭은 화면 이동에만 쓴다. 저장, 넘기기 같은 동작을 탭에 두지 않는다.
3. 앱을 열면(로그인 직후, 다시 실행) 늘 터미널 탭에서 시작한다.
4. 다음 동안에는 탭바를 숨기고, 끝나면 다시 보여 준다.
   - 입력창을 눌러 키보드가 올라와 있는 동안
   - 메뉴 시트나 확인 창이 떠 있는 동안
   - 고르기 중(고른 칩과 `공유 · 복사 · 묶음 _` 줄이 떠 있는 동안)
5. 로그인 전 화면(ACC-001)에는 탭바가 없다.
6. 탭을 옮겨도 각 탭의 상태(터미널 출력 기록과 치던 글, 보관함의 보던 위치, 설정의 열린 화면)는 그대로 남는다.
7. 선택은 탭을 넘어 같이 쓴다. 보관함에서 고른 자료를 터미널에서 `넘기기`할 수 있다.
8. 보고 있는 탭을 다시 누르면, 터미널은 맨 아래 최신 출력으로, 보관함은 맨 위로, 설정은 첫 화면으로 돌아간다.
9. 탭에는 배지를 달지 않는다. 처리 상태는 터미널 상태줄에만 보여 준다.
10. 탭바는 맨 아래 안전 영역 바로 위에 둔다. 터미널 탭의 명령 버튼과 입력줄은 탭바 위에 둔다.
11. 설정 탭에 둘 항목은 이 정책에서 정하지 않고 각 정책을 따른다(예: 기기와 AI 도구 연결은 ACC-002).

## 값

| 항목 | 값 | 경계 |
| :--- | :--- | :--- |
| 탭 수 | 3개 | 늘리거나 줄이려면 이 정책을 고친다 |
| 탭 이름 | `터미널` · `보관함` · `설정` | 한글만. 아이콘과 이름을 함께 보인다 |
| 시작 탭 | 터미널 | 마지막에 본 탭을 기억하지 않는다 |
| 웹에서 탭을 쓰는 폭 | 600px 미만 | 600px 이상은 이 정책 밖 |
| 탭 터치 목표 | 44px 이상 | 모바일 시안 규칙 9와 같다 |

## 검증 방법

| 종류 | 확인할 것 |
| :--- | :--- |
| 자동 테스트 | 앱을 다시 열면 늘 터미널 탭인지 |
| 자동 테스트 | 탭을 옮겼다 돌아와도 출력 기록·치던 글·선택이 남는지 |
| 기기 확인 | 키보드가 올라오면 탭바가 숨고, 입력줄이 키보드와 홈 표시줄에 가리지 않는지(iOS Safari, Android Chrome, 앱) |
| 리뷰 | 시안에서 탭에 동작이나 배지가 없는지 |
