# COM-012 웹은 밝게·어둡게·시스템 따름 중 고른 테마를 이 기기에만 남긴다
- 상태: 검토 중 (PO 확인 대기)
- 적용 범위: 웹. iOS·Android 앱은 기기 설정을 따르고 이 정책 밖이다

> **요약** 설정에서 테마를 세 가지 중에 고른다. 기본은 시스템 따름이고, 고른 값은 이 브라우저에만 남는다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 테마 | 화면의 밝은·어두운 색 묶음(디자인 시스템 두 테마 토큰) |

## 규칙

1. 테마는 `시스템 따름`, `밝게`, `어둡게` 세 가지다.
2. 처음에는 `시스템 따름`이다. 기기의 밝은·어두운 모드가 바뀌면 바로 따라 바뀐다.
3. 고른 값은 이 기기(브라우저)에만 남기고 서버에 올리지 않는다. 다른 기기는 각자 고른다.
4. 로그아웃해도 고른 테마는 남는다. 로그인 전 화면도 고른 테마를 따른다.
5. 남긴 값을 읽지 못하면(저장소 막힘, 모르는 값) `시스템 따름`으로 보인다. 오류를 알리지 않는다.
6. 두더지 색은 테마와 상관없이 같다.

## 값

| 항목 | 값 | 경계 |
| :--- | :--- | :--- |
| 기본 테마 | 시스템 따름 | |
| 저장 위치 | 이 브라우저 | 계정에 남기지 않음 |
