# COM-011 웹 화면은 폭에 따라 사이드바·아이콘 레일·하단 탭으로 나누어 터미널·보관함·설정을 오간다
- 상태: 검토 중 (PO 확인 대기)
- 적용 범위: 웹(브라우저). 데스크톱 앱 창 배치는 #140에서 따로 정한다

> **요약** 넓은 웹은 왼쪽 사이드바와 오른쪽 자세히 보기 칸, 중간 폭은 아이콘 레일, 좁은 폭은 하단 탭(MOB-001)으로 같은 세 화면을 오간다. 폭이 바뀌어도 보던 화면과 상태는 그대로다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 사이드바 | 넓은 웹 왼쪽의 이동 줄. 세 화면 이름과 보관함 구역(묶음·저장한 찾기·자동 묶음)을 보인다 |
| 아이콘 레일 | 중간 폭 웹 왼쪽의 좁은 이동 줄. 세 화면의 아이콘과 이름만 보인다 |
| 자세히 보기 칸 | 넓은 웹에서 목록 오른쪽에 여는 자세히 보기(ARC-011 규칙 8) |

## 규칙

1. 폭이 1008px 이상이면, 웹은 왼쪽에 사이드바를 두고, 보관함에서 자료를 열면 목록 오른쪽 칸에 자세히 보기를 연다.
2. 폭이 600px 이상 1008px 미만이면, 웹은 왼쪽에 아이콘 레일을 두고, 자세히 보기는 새 화면으로 연다.
3. 폭이 600px 미만이면, 웹은 하단 탭을 쓴다(MOB-001).
4. 이동 항목은 어느 폭에서나 `터미널`, `보관함`, `설정` 세 개이고 이 차례다. 이동에만 쓰고 배지를 달지 않는다(MOB-001 규칙 2·9와 같다).
5. 폭이 바뀌어도(창 크기 조절, 기기 회전) 보던 화면과 각 화면의 상태는 그대로 남는다(MOB-001 규칙 6과 같다).
6. 웹을 열면 늘 터미널에서 시작한다(MOB-001 규칙 3과 같다).
7. 선택은 화면을 넘어 같이 쓴다(MOB-001 규칙 7과 같다).

| 하단 탭 폭 기준 | 600px | 600px 미만이면 탭(MOB-001) |
