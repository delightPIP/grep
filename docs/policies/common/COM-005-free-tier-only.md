# COM-005 그렙은 돈이 드는 서비스를 쓰지 않고 무료 플랜·무료 한도 안에서만 돈다
- 상태: 검토 중 (개발자 확인 대기)
- 적용 범위: 서버, 데이터베이스, 파일 저장소, 인증, 외부 LLM(요약·태그·글자 읽기), 배포. 발표(2026-12-01)까지의 프로젝트 기간 전체

> **요약** 그렙은 교육 과정 프로젝트라 결제 수단이 필요한 서비스를 쓰지 않는다. 무료 한도가 바닥나면 저장·찾기·넘기기는 그대로 되고, AI 처리(요약·태그·글자 읽기)만 멈춘다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 무료 한도 | 제공사가 돈을 받지 않고 주는 사용량(무료 플랜, 무료 크레딧) |
| AI 처리 | 외부 LLM을 부르는 일. 요약, 태그, 이미지 글자 읽기(ARC-005) |

## 규칙

> **주의** 결제 수단을 등록한 계정은 한도를 넘으면 그대로 청구된다. 결제 수단을 등록해야만 쓸 수 있는 제공사라면 쓰기 전에 PO에게 묻는다.

1. 서버, 데이터베이스, 파일 저장소, 인증, 배포는 무료 플랜으로 쓴다. 무료 플랜이 없는 서비스는 쓰지 않는다.
2. 외부 LLM은 무료 한도 안에서만 부른다. 결제 수단을 등록해야 한다면, 제공사 콘솔의 지출 상한을 가장 낮은 값으로 건다.
3. 무료 한도나 지출 상한에 닿으면, 서버는 AI 처리만 멈추고 그 자료를 `failed`로 둔다(ARC-005). 저장, `찾기`(제목·출처·본문), `고르기`, `넘기기`는 그대로 된다.
4. 한 계정의 하루 AI 처리 건수가 상한에 닿으면, 서버는 그날 나머지 자료의 AI 처리를 하지 않는다.
5. 북마크 가져오기는 한 번에 상한 건수까지만 받는다. 넘는 항목은 받지 않고 결과에 건수로 알린다.
6. 유료 플랜으로 올려야 풀리는 문제는 정책을 바꾸지 않고 발표의 "다음 단계"로 적는다.

## 값

| 항목 | 값 | 경계 |
| :--- | :--- | :--- |
| 월 지출 | 0원 | 결제 수단을 등록했다면 지출 상한을 최저로 |
| 계정당 하루 AI 처리 | 50건 (가정값, 개발자 확인) | 50건째까지 처리. 한국 시간 0시에 다시 센다 |
| 북마크 한 번 가져오기 | 200건 (가정값, 개발자 확인) | 200건째까지. 하루 AI 처리 상한은 따로 적용 |
| 파일 하나 크기 | 20MB (공통 열린 질문의 임시값 유지) | 20MB 이하 저장 |

## 근거

- PO 결정(2026-11-26): "진짜 프로젝트성이라 돈 안 드는 방향으로. 개발자가 확인 후 수정할 수 있게"
- 외부 전문가 검토(2026-11-26): 무료 서비스라도 저장마다 유료 API를 부르면 한 계정이 예산을 소진할 수 있다. 권장 하루 20~100건, 북마크 100~200건
- 개발자 백엔드 설계 5절 비용 추정
- 구현: 아직 없음

## 검증 방법

| 종류 | 확인할 것 |
| :--- | :--- |
| 수동 확인 | 쓰는 서비스마다 플랜이 무료인지, 결제 수단이 등록되지 않았거나 지출 상한이 걸렸는지 |
| 자동 테스트 | 하루 처리 상한째 자료까지 처리되고 그다음부터 `failed`가 되는지. 저장은 계속 되는지 |

## 비고

- 개발자 확인할 것: ① 지금 쓰는(쓸) 서비스가 모두 무료 플랜으로 되는지(Supabase, 파일 저장소, 배포, 외부 LLM) ② 무료 한도로 데모 시드 자료를 다 처리할 수 있는지 ③ 하루 50건·북마크 200건이 개발과 데모에 충분한지. 값을 바꾸면 이 표를 고치고 상태를 확정으로 바꾼다.
- 외부 LLM 무료 플랜의 데이터 조건은 COM-002를 따른다.
