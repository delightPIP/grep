# COM-001 같은 링크나 같은 파일을 다시 저장하면 새로 만들지 않고 기존 자료를 알린다
- 상태: 확정
- 적용 범위: 링크·파일을 저장하는 모든 경로(붙여 넣기, 공유, 끌어다 놓기, 파일 선택, 북마크 가져오기)와 모든 플랫폼. 판정은 서버가 한다(ADR-0001)

> **요약** 같은 사용자가 이미 저장한 링크(정규화한 주소 기준)나 파일(내용 해시 기준)을 다시 저장하면, 서버는 새 자료를 만들지 않고 기존 자료를 돌려주며 클라이언트는 이미 저장했다고 알린다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 정규화 주소 | 아래 "값"의 규칙을 적용한 링크 주소. 같은 링크인지는 이 값으로만 판정한다 |
| 내용 해시 | 파일 바이트 전체의 SHA-256 값 |
| 같은 자료 | 같은 사용자의 자료 중 정규화 주소 또는 내용 해시가 같은 것 |

## 규칙

1. 링크를 저장하면, 서버는 정규화 주소를 만들어 같은 사용자의 기존 자료와 비교한다.
2. 파일을 저장하면, 서버는 내용 해시를 만들어 같은 사용자의 기존 자료와 비교한다.
3. 같은 자료가 있으면, 서버는 새 자료를 만들지 않고 기존 자료를 돌려주며 응답에 "이미 있음"을 표시한다.
4. 응답에 "이미 있음"이 있으면, 클라이언트는 알림을 한 번 보여 주고 기존 자료를 보여 준다. 저장을 막는 오류로 다루지 않는다.
5. 북마크 가져오기에서 같은 자료가 있으면, 서버는 그 항목을 건너뛰고 결과에 건너뛴 건수로 센다.
6. 다른 사용자의 자료와는 비교하지 않는다.
7. 휴지통에 있는 자료(ARC-008)와 같으면, 서버는 새로 만들지 않고 휴지통에 있다고 알린다. 영구 삭제한 자료는 비교 대상이 아니다. 영구 삭제한 자료와 같은 링크나 파일은 새로 저장한다.

## 값

| 항목 | 값 | 경계 |
| :--- | :--- | :--- |
| 스킴 | `http`와 `https`는 같은 것으로 본다 | 그 밖의 스킴은 링크로 저장하지 않고 글로 저장한다 |
| 호스트 | 소문자로 바꾸고 앞의 `www.`를 지운다 | `www`가 아닌 하위 도메인(`m.` 등)은 그대로 둔다 |
| 경로 끝 | 끝의 `/` 하나를 지운다 | 경로가 `/` 하나뿐이면 빈 경로로 본다 |
| `#` 뒤 | 지운다 | `#/`로 시작하면 실제 주소로 보고 남긴다 |
| 쿼리 파라미터 | 이름순으로 정렬한다. 추적용 꼬리표 `utm_*`, `fbclid`, `gclid`, `igsh`, `si`, `ref_src`는 지운다 | 꼬리표를 지운 뒤 쿼리가 비면 `?`도 지운다 |
| 짧은 주소 | `youtu.be/<ID>`는 `youtube.com/watch?v=<ID>`로 바꾼다 | 그 밖의 단축 주소는 "비고"의 나중에 붙일 것 |

## 사용자 문구

| 상황 | 제목 | 본문 | 버튼 |
| :--- | :--- | :--- | :--- |
| 같은 자료를 다시 저장함 | 없음 | `! 이미 저장됨 → N번 (새로 만들지 않음)` (N은 기존 자료의 고유 번호, ARC-001) | 없음(기존 자료를 함께 보여 줌) |

## 비고

- 사용자 문구는 PO가 2026-11-25에 확정했다(PR #3 코멘트). 같은 날 화면 문구를 건조한 터미널 말투로 바꾸며 PR #5에서 다시 정했다(기준: `docs/planning/commands.md` 6절).
- 나중에 붙일 것:
  - 단축 주소(`bit.ly`, `t.co` 등)의 리다이렉트를 따라가 최종 주소로 판정
  - 페이지가 밝힌 대표 주소(`canonical`, `og:url`)로 판정
  - 둘 다 저장 뒤 처리 단계에서 찾아 저장해 두고, 다음 저장 때 정규화 주소와 함께 비교한다. 비슷한 내용의 자료 알림은 이 정책이 아니라 의미 검색(F15) 쪽에서 다룬다.
- 값 표에 없는 부분은 개발자가 정했다(2026-11-27): 정규화 주소는 `https://`로 적는다. 포트·경로 대소문자·퍼센트 인코딩은 그대로 두고, 사용자 정보(`user@`)는 버린다. 추적 꼬리표 이름은 대소문자를 가리지 않는다. 한글 도메인(IDN)은 아직 링크로 받지 않는다.
- 규칙이 바뀌면 기존 자료의 정규화 주소를 다시 계산한다. 그 결과 겹치는 자료는 합치지 않고 그대로 둔다.
