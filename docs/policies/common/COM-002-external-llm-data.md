# COM-002 자료 내용은 허용 제공사의 외부 LLM API로만 보내고, 프로젝트 기간에는 팀이 만든 자료만 넣어 무료 플랜을 쓴다
- 상태: 검토 중 (개발자 확인 대기)
- 적용 범위: 서버가 외부 LLM을 부르는 모든 경우(요약, 이미지 글자 읽기, 나중의 임베딩)

> **요약** 서버는 사용자가 저장한 자료의 내용(본문 텍스트, 이미지)을 요약과 글자 읽기를 위해 외부 LLM으로 보낼 수 있다. 계정 정보는 보내지 않는다. 그렙은 발표까지의 프로젝트라 실제 사용자를 받지 않고, 팀이 만든 자료와 공개 자료만 넣는다. 그래서 돈이 들지 않게 무료 플랜을 쓸 수 있다(COM-005). 실제 사용자를 받기 전에는 학습 미사용 조건의 API로 되돌린다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 외부 LLM | 그렙 밖의 제공사가 운영하는 언어 모델 API |
| 자료 내용 | 사용자가 저장한 자료의 본문 텍스트, 이미지, 그리고 요약에 필요한 제목과 출처 |
| 허용 제공사 | 개발자가 고른 외부 LLM 제공사. 프로젝트 기간에는 무료 플랜도 된다. 실제 사용자를 받으면 입력과 출력을 모델 학습에 쓰지 않는다고 약관에 명시한 API만 된다 |
| 프로젝트 기간 | 발표(2026-12-01)까지. 실제 사용자 없이 팀 계정만 쓰는 기간 |

## 규칙

> **주의** 사용자가 자료를 지워도 이미 외부 LLM으로 보낸 데이터는 그 제공사의 보관 정책을 따른다. 그렙이 제공사 쪽 데이터를 지울 수는 없다.

1. 서버는 자료 내용을 허용 제공사의 API로만 보낸다.
2. 서버는 계정 정보(이메일 등), 인증 토큰, 다른 사용자의 자료를 외부 LLM으로 보내지 않는다.
3. 프로젝트 기간에는 제공사의 무료 플랜을 쓸 수 있다. 이때 그렙 계정에는 팀이 만든 자료와 공개 자료만 넣는다. 회사 자료, 개인정보가 든 자료, 남의 자료는 넣지 않는다.
4. 허용 제공사가 장애이면, 서버는 허용 제공사가 아닌 다른 제공사로 자동 전환하지 않는다. 요약과 글자 읽기는 나중에 다시 시도한다.
5. 제공사를 추가하거나 바꾸면, 약관에서 학습 사용 여부와 입력 보관 기간을 확인하고 그 결과를 이 정책의 비고에 기록한다.
6. 실제 사용자를 받기 전에는, 서버는 무료 플랜을 끊고 학습 미사용 조건의 API로 바꾼다. 바꾸기 전에 이 정책을 다시 확정한다.

## 값

| 항목 | 값 | 경계 |
| :--- | :--- | :--- |
| 보낼 수 있는 것 | 자료의 본문 텍스트, 이미지, 제목, 출처 | 이 목록에 없는 것은 보내지 않는다 |
| 보내지 않는 것 | 계정 정보, 인증 토큰, 다른 사용자의 자료 | 예외 없음 |

## 검증 방법

| 종류 | 확인할 것 |
| :--- | :--- |
| 자동 테스트 | 외부 LLM 호출 요청에 계정 정보·토큰이 들어가지 않는지. 구현 후 기입 |
| 수동 확인 | 사용하는 제공사의 약관에 학습 미사용 조건이 있는지(비고에 기록) |

## 비고

- 개발자 확인할 것: 쓸 제공사와 플랜(무료 플랜이 데모 시드 자료를 처리할 만큼 되는지), 그 플랜이 입력을 학습에 쓰는지와 보관 기간. 확인하면 아래 기록에 적고 상태를 확정으로 바꾼다.
- 외부 전문가 검토(2026-11-26): "학습에 쓰지 않음"과 "보관하지 않음"은 다르다. 제공사는 악용 감시용으로 입력을 일정 기간 보관할 수 있다. 연결(ARC-009)이나 넘기기로 AI 도구가 받은 내용에는 이 정책이 적용되지 않는다.
- 허용 제공사 확인 기록: 아직 없음. 기본 제공사(ADR-BCK-003, Anthropic)의 약관 원문 확인이 필요하다.
