# COM-002 자료 내용은 학습에 쓰지 않는 조건의 유료 외부 LLM API로만 보낸다
- 상태: 확정
- 적용 범위: 서버가 외부 LLM을 부르는 모든 경우(요약, 이미지 글자 읽기, 나중의 임베딩)

> **요약** 서버는 사용자가 저장한 자료의 내용(본문 텍스트, 이미지)을 요약과 글자 읽기를 위해 외부 LLM으로 보낼 수 있다. 다만 입력과 출력을 모델 학습에 쓰지 않는다고 약관에 명시한 유료 API로만 보내고, 계정 정보는 보내지 않는다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 외부 LLM | 이 서비스 밖의 제공사가 운영하는 언어 모델 API |
| 자료 내용 | 사용자가 저장한 자료의 본문 텍스트, 이미지, 그리고 요약에 필요한 제목과 출처 |
| 허용 제공사 | 입력과 출력을 모델 학습에 쓰지 않는다고 약관에 명시한 유료 API 제공사 |

## 규칙

> **주의** 사용자가 자료를 지워도 이미 외부 LLM으로 보낸 데이터는 그 제공사의 보관 정책을 따른다. 이 서비스가 제공사 쪽 데이터를 지울 수는 없다.

1. 서버는 자료 내용을 허용 제공사의 API로만 보낸다.
2. 서버는 계정 정보(이메일 등), 인증 토큰, 다른 사용자의 자료를 외부 LLM으로 보내지 않는다.
3. 제공사의 무료 플랜은 쓰지 않는다.
4. 허용 제공사가 장애이면, 서버는 허용 제공사가 아닌 다른 제공사로 자동 전환하지 않는다. 요약과 글자 읽기는 나중에 다시 시도한다.
5. 제공사를 추가하거나 바꾸면, 약관에서 학습 미사용 조건을 확인하고 그 결과를 이 정책의 비고에 기록한다.

## 값

| 항목 | 값 | 경계 |
| :--- | :--- | :--- |
| 보낼 수 있는 것 | 자료의 본문 텍스트, 이미지, 제목, 출처 | 이 목록에 없는 것은 보내지 않는다 |
| 보내지 않는 것 | 계정 정보, 인증 토큰, 다른 사용자의 자료 | 예외 없음 |

## 예외

없음. 모바일 앱의 기기 안 글자 인식은 외부로 보내는 것이 아니라 이 정책의 대상이 아니다.
