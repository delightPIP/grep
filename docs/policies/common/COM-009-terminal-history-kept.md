# COM-009 터미널 출력 기록·치던 글·선택은 이 기기에 남기고, 로그아웃하거나 다른 계정으로 로그인하면 지운다
- 상태: 확정
- 적용 범위: 모든 플랫폼의 터미널 화면(웹, 모바일 터미널 탭, 데스크톱 빠른 창). 새로 고침, 창·탭을 닫고 다시 열기, 앱 다시 실행, 로그인·로그아웃

> **요약** 그렙을 다시 열어도 보던 출력, 치던 글, 고른 자료가 그대로 있다. 로그아웃하거나 다른 계정으로 로그인할 때만 지운다. 남긴 기록이 없을 때 로그인하면 자료가 있어도 상태줄과 입력줄만 보이고, `최근`은 사용자가 친다.

## 용어

| 용어 | 뜻 |
| :--- | :--- |
| 터미널 기록 | 터미널 화면의 출력 기록, 입력줄에 치던 글, 선택 |
| 이 기기 | 그 브라우저 또는 그 앱 |

## 규칙

> **주의** 터미널 기록에는 자료 제목과 요약이 들어 있다. 공용 컴퓨터에서 로그아웃하지 않으면 다음 사람이 볼 수 있다.

1. 클라이언트는 터미널 기록을 이 기기에 남긴다. 새로 고침, 창·탭을 닫고 다시 열기, 앱 다시 실행 뒤에도 그대로 보인다.
2. `로그아웃`이나 `로그아웃 모든기기`를 하면, 클라이언트는 이 기기의 터미널 기록을 지운다.
3. 이 기기에서 다른 계정으로 로그인하면, 클라이언트는 앞 계정의 터미널 기록을 지운다.
4. 로그인이 만료된 뒤 같은 계정으로 다시 로그인하면, 클라이언트는 터미널 기록을 되살린다(ACC-001 규칙 7과 같은 방향). 기다리던 확인은 취소된 것으로 본다(COM-007).
5. 남긴 터미널 기록이 없을 때 로그인하면, 클라이언트는 자료 0건이면 첫 화면을 보이고, 1건 이상이면 상태줄과 입력줄만 보인다. `최근`을 저절로 띄우지 않는다.
6. 다시 열었을 때 선택 안의 자료가 지워졌으면(휴지통 포함), 클라이언트는 그 자료를 선택에서 빼고 상태줄 숫자를 맞춘다. 출력 기록은 그때 찍힌 그대로 둔다.
7. 모바일 앱은 다시 열면 늘 터미널 탭에서 시작한다(MOB-001 규칙 3). 그 탭의 기록은 이 정책을 따른다.

| 항목 | 값 | 경계 |
| :--- | :--- | :--- |
| 남기는 곳 | 이 기기 | 서버에는 남기지 않는다. 저장 방식은 개발자가 정한다 |
| 지우는 때 | 로그아웃, 모든 기기 로그아웃, 다른 계정 로그인 | 로그인 만료는 지우지 않는다 |
