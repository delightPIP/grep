## 3. 개요

- 왜: 저장해 둔 한국어 자료를 `찾기`로 찾아 AI 도구에 붙여 넣을 글로 복사하기까지 1분 안(핵심 성공 기준, PRD 7절. 조건은 30건 이상 저장된 상태, `도움말`만 보고, 2건).
- 데모 필수(개발자가 11/29까지 보장, STATE:308): 담기(저장·같은 링크 알림·요약), 찾기, 고르기·넘기기. 로그인과 첫 화면 도움말도 데모 경로에 있다(PRD 7절).
- 되면 보여 줄 것(순서): 묶음(F12) → 스크린샷 글자로 찾기(F16) → AI 도구 연결(F7). 이 문서는 작업 단위로 쪼개지 않았다.
- 만들지 않는 것(데모 경로 밖): 북마크 가져오기(F8), 뜻으로 찾기(F15), 가까운 명령 제안(F17), 기기 간 동기화(F6), 웹 자세히 보기(04 질문 4), 본문 넣기 문법(handoff-format 4절).
- `[범위 밖]` 실사용자 전: 탈퇴, 처리방침·약관, 학습 미사용 API로 바꾸기, 데이터 전송 고지(05 ST-34). 01 문서 5절.
