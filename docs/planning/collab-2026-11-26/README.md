# PO·디자이너 에이전트 협업 산출물 (2026-11-26)

PO 에이전트와 디자이너 에이전트가 po-workflow 스킬 7개를 나눠 쓰고, 5라운드에 걸쳐 피드백을 주고받으며 바로 고친 결과다. 관문은 발표(2026-12-01)이고, 데모 필수 흐름은 담기 → 찾기 → 넘기기다.

**이 폴더의 판단은 `AI 제안·미확인`이다. 단, 04 질문 1~12와 3절 승인 두 개는 2026-11-26 PO가 정했다(아래 "PO가 답한 것").** 개발자는 아직 보지 않았다. 4라운드까지는 정책·ADR·STATE 결정 로그를 고치지 않았고, PO 답 뒤 정책 ARC-010·ARC-002·ARC-004와 STATE 12절을 고쳤다. 기존 기획 문서는 이미 확정된 PO 결정이 덜 반영된 일곱 곳만 고쳤다([03](03-po-decision-propagation.md) 2절).

## PO가 답한 것

2026-11-26 실제 PO(김태인)가 [04](04-po-decision-questions.md) 질문 1~12에 모두 추천안(A)으로 답했다: 담기 장면은 찾기 앞, 넘기기 실패 문구를 둠, 칩은 찍기만(`펼치기`는 예외), 목록 태그 앞 3개(웹 자세히 보기는 발표 뒤), 무대 요약은 기다리지 않음, 붙여 넣은 글 제목은 첫 줄(24자까지), S07 요약 없음은 정상, 10건 이하면 `앞10` 없음, 샘플은 받은 번호 범위를 알림, 명령어 설명서 데모 기준 확정, 끌어다 놓기 안내는 COM-004, 요약 없는 줄도 `AI 요약` 칸. 3절 승인 두 개(예시 글자 수 442자, 태그 지우기 반영)도 승인했다. 결정자는 `김태인 (AI 제안 수용)`이고 [STATE](../STATE.md) 12절(STATE:320-332)에 남겼다. 저장소 전체 반영은 [03](03-po-decision-propagation.md) 7절.

설문 시트는 2026-11-26 PO가 확인했다(6건 맞음, [02](02-po-survey-tally.md) 7절). 시드 내용도 같은 날 PO가 그대로 확정했다. 열린 채로 남은 것: 04 질문 13~21.
