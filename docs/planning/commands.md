# 명령어 설명서

- 작성일: 2026-11-25
- 상태: 데모 기준 확정(2026-11-26 PO 결정, [STATE](STATE.md) 12절). 시점 인자 이름·영문 표기와 휴지통 명령 이름은 제안으로 남는다
- 근거: [기획서](PRD.md) 8절, PO 결정(2026-11-25, [STATE](STATE.md) 12절)

그렙의 터미널 화면에서 쓰는 명령과 화면 문구를 진짜 터미널의 설명서(`man` 페이지)처럼 정리한다. 화면의 `도움말`과 `설명 <명령>`은 이 문서의 내용을 그대로 보여 준다. 화면 문구의 기준은 6절이다.

## 1. 원칙 (PO 결정)

1. **기본 명령은 한글이다.** 모든 명령에 영문판이 있고, 둘은 완전히 같은 일을 한다. 한 줄 안에서 섞어 써도 된다.
2. **기존 터미널·프롬프트의 명령 이름을 쓰지 않는다.** 영문판도 맥 터미널, 윈도우 명령 프롬프트, PowerShell, 리눅스 셸에 이미 있는 이름(`grep`, `ls`, `rm`, `cp`, `copy`, `find`, `help`, `man`, `cd` 등)과 겹치지 않게 고른다. 진짜 터미널에서 그렙의 명령을 쳐도 다른 명령이 실행되지 않게 하고, 반대로 사용자가 진짜 명령으로 착각하지 않게 하기 위해서다. 서비스 이름이 그렙(grep)이어도 `grep`을 명령으로 쓰지 않는다. 다만 사용자가 진짜 터미널 명령을 쳤을 때 같은 일을 하는 명령이 분명하면 입력으로 받아 실행하고, 실행한 그렙 명령을 한 줄로 알려 준다(5절, 2026-11-26 PO 결정). 정식 이름과 `도움말` 목록에는 넣지 않는다.
3. **진짜 터미널처럼 보이고 움직인다.** 프롬프트, 명령 한 줄, 결과 한 덩어리, 이어 쓰기(`|`), 명령별 설명서가 있다. 진짜 명령줄 도구는 아니다.
4. **문구는 진짜 터미널처럼 건조하게 쓴다.** 출력은 문장이 아니라 로그다. 해요체·반말 어미 없이 `저장됨`, `4건`, `없는 명령: 찻기`처럼 쓴다(6절).

한글을 기본으로 하면 좋은 점: 한국어 검색어를 칠 때 한/영 전환 없이 `찾기 결제`처럼 한 번에 친다. 입문 사용자가 명령의 뜻을 바로 안다.

## 2. 명령 한눈에 보기

`도움말`(영문 `guide`)을 치면 나오는 화면이다.

```text
그렙 ~ $ 도움말

  저장: 링크·글 붙여 넣기, 파일 끌어다 놓기. 명령: 한글·영문 같음

  담기     keep      자료 저장
  최근     recent    최근 자료 목록
  찾기     seek      검색
  고르기   pick      번호로 선택
  넘기기   handoff   AI 도구용 글 복사
  묶음     pack      선택에 이름 붙이기
  고치기   revise    제목·요약 수정
  버리기   drop      삭제
  되살리기 revive    휴지통에서 돌리기
  휴지통   bin       휴지통 목록
  휴지통 비우기 bin empty 휴지통 영구 삭제
  가져오기 bring     북마크 파일 가져오기
  연결     plug      AI 도구 연결
  로그아웃 signout   로그아웃
  도움말   guide     명령 목록
  설명     about     명령 설명

  → 예: 찾기 결제 | 넘기기 · 자세히: 설명 찾기
```

| 한글 | 영문 | 기능 | 우선순위 |
|---|---|---|---|
| `담기` | `keep` | F1 | P0 |
| `최근` | `recent` | F3 | P0 |
| `찾기` | `seek` | F3 | P0 |
| `열기` | `peek` | F2·F3 | P0, 발표 뒤(데모 범위 밖, `도움말` 목록에 아직 없음) |
| `찾아두기` | `gather` | F3 (보관함 저장한 찾기) | P1, 발표 뒤(데모 범위 밖, `도움말` 목록에 아직 없음) |
| `고르기` | `pick` | F4 | P0 |
| `넘기기` | `handoff` | F4 | P0 |
| `고치기` | `revise` | F14 | P0 |
| `버리기` | `drop` | F14 | P0 |
| `되살리기` | `revive` | F14 | P0 (ARC-008) |
| `휴지통` | `bin` | F14 | P0 (ARC-008) |
| `휴지통 비우기` | `bin empty` | F14 | P0 (ARC-008) |
| `도움말` | `guide` | F5 | P0 |
| `설명` | `about` | F5 | P0 |
| `묶음` | `pack` | F12 | P1 |
| `가져오기` | `bring` | F8 | P1 |
| `로그아웃` | `signout` | F6a | P0 |
| `연결` | `plug` | F7 | P1 |

휴지통 명령 세 줄은 ARC-008에 있고 이름은 개발자가 제안대로 확정했다(2026-11-27, #93). 위 `도움말` 화면에 뜻 문구와 함께 더했다(2026-11-27 사용자 결정, #96).

## 3. 명령별 설명서

`설명 <명령>`(영문 `about <명령>`)을 치면 아래 형식으로 나온다. 설명 줄은 화면에 그대로 나가는 문구다.

### 담기 (keep)

- 사용법: `담기 <링크 또는 글>`
- 설명: 자료 저장. 링크·글은 붙여 넣기만 해도 저장. 이미 저장된 링크·파일은 새로 만들지 않음(F21)
- 예: `담기 https://example.com/payments-guide`

### 최근 (recent)

- 사용법: `최근 [개수 또는 시점]`
- 설명: 최근 저장 자료 목록. 개수 생략 시 10건. 개수를 붙이면 `→ 더 보기`도 그 개수만큼 이어 붙인다(2026-11-27 개발 제안, PO 수용, #60). 시점을 붙이면 그 기간 자료만(F22). 여러 주에 걸치면 주 단위 구분선
- 예: `최근`, `최근 20`, `최근 지난달`

### 찾기 (seek)

- 사용법: `찾기 <검색어> [시점]`
- 설명: 제목·본문·요약·이미지 속 글자·태그에서 검색. 최근 저장 순. 10건 초과 시 앞 10건과 전체 건수. 마지막 낱말이 시점이면 그 기간 자료만(F22)
- 태그: `#`으로 시작하는 낱말은 자동 태그로 거름. 여러 조건은 모두 맞는 자료만(ARC-002)
- 예: `찾기 결제`, `찾기 onboarding 화면`, `찾기 #결제 위젯`, `찾기 결제 3주전`
- 목록: 자료마다 두 줄. 첫 줄은 자료 번호·제목·출처·저장 시각, 둘째 줄은 흐린 요약 한 줄. 태그는 앞 3개(ARC-002 규칙 4, 2026-11-26 PO 결정). 10건 초과면 맨 아래 `→ 더 보기`(다음 10건을 이어 보여 줌)

### 시점 (찾기·최근 공통, F22)

`찾기`와 `최근` 뒤에 붙여 저장한 기간을 좁힌다. 명령이 아니라 인자라서 `도움말` 목록에는 따로 나오지 않고, `설명 찾기`·`설명 최근`에 함께 나온다. 이름과 범위는 (제안)이며 화면 시안에서 확정한다.

| 한글 | 영문 | 범위 |
|---|---|---|
| `오늘`, `어제` | `today`, `yesterday` | 그날 하루 |
| `이번주`, `지난주` | `thisweek`, `lastweek` | 월요일에 시작하는 그 주 |
| `이번달`, `지난달` | `thismonth`, `lastmonth` | 그 달 |
| `N일전`, `N주전`, `N달전` | `Nd`, `Nw`, `Nmo` | N일 전 하루, N주 전 그 주, N달 전 그 달 |
| `11월` | `nov` | 가장 가까운 지난(또는 이번) 11월 |

- 시각은 한국 시간 기준이다.
- `찾기`에서는 마지막 낱말만 시점으로 본다. 시점 낱말 자체를 찾으려면 따옴표로 감싼다: `찾기 "지난달"`.
- `최근`에는 개수와 시점 중 하나만 붙인다. 시점을 붙이면 그 기간 자료를 최근 순으로 앞 10건과 전체 건수까지 보여 준다.
- 앞으로의 시점(`다음주`)과 없는 시점(`13월`)은 받지 않는다.

### 찾아두기 (gather)

- 구현: 발표 뒤. 데모 범위 밖이고 `도움말` 목록에 아직 넣지 않는다(2026-11-26 PO 결정, STATE 12절)
- 사용법: `찾아두기`, `찾아두기 <검색어>`, `찾아두기 <검색어> 지우기`
- 설명: 검색어를 저장해 두면 맞는 자료가 저절로 모임(보관함의 저장한 찾기, ARC-007). 이름은 검색어 그대로. 이미 저장한 검색어면 결과만 보여 줌. 결과·순서·이어 쓰기는 `찾기`와 같음. 시점으로 끝나는 검색어는 저장하지 않음. `찾아두기`만 치면 목록, `지우기`는 저장한 찾기만 지움(자료는 남음, ARC-012)
- 예: `찾아두기 텀블러 캠페인`, `찾아두기 #캠페인`, `찾아두기 텀블러 캠페인 | 넘기기`

### 열기 (peek)

- 구현: 발표 뒤. 데모 범위 밖이고 `도움말` 목록에 아직 넣지 않는다(2026-11-26 PO 결정, STATE 12절)
- 사용법: `열기 <번호>`
- 설명: 자료 하나의 자세히 보기. 제목·출처·저장 시각·처리 상태·AI 요약·태그·들어 있는 묶음·본문(접힘)·원본 미리보기(이미지·PDF). 목록의 제목을 눌러도 열림. 번호는 하나만(ARC-011)
- 예: `열기 131`

### 고르기 (pick)

- 사용법: `고르기 <번호...>`
- 설명: 자료 번호로 선택. 번호는 목록 각 줄 앞의 자료 고유 번호(ARC-001)이며 바로 앞 목록에 없던 번호도 됨. 선택한 자료는 넘기기·묶음 대상
- 예: `고르기 131 140`
- 빼기: `고르기 빼기 <번호...>`는 선택에서만 뺀다. `고르기 비우기`는 선택을 모두 푼다. 입력줄 위 선택 칩을 눌러 빼도 같은 명령으로 기록한다(2026-11-26 PO 결정)

### 넘기기 (handoff)

- 사용법: `넘기기 [묶음 이름]`
- 설명: 선택한 자료 또는 묶음을 AI 도구용 글로 복사. 자료마다 제목 · 출처 · 저장 시각 · 요약. 넘길 글의 내용은 기획서 8절 정의를 따른다
- 예: `넘기기`, `넘기기 결제조사`

### 고치기 (revise)

- 사용법: `고치기 <번호>`, 태그 지우기 `고치기 <번호> -#태그`(ARC-002 규칙 2, 문법 개발자 확정 2026-11-27)
- 설명: 제목·요약 수정. 직접 고친 요약은 자동 요약이 덮어쓰지 않음. 태그는 붙이거나 고칠 수 없고 지우기만 함. 지운 태그는 다시 붙지 않음(ARC-002)
- 예: `고치기 131`, `고치기 131 -#위젯`
- 고치는 방식: 출력 블록 안에 제목과 `요약 (직접 고침)` 두 칸이 열리고 첫 칸에 초점. Enter 저장, Esc 취소, Tab 다음 칸. 모달은 쓰지 않는다(2026-11-26 PO 결정)

### 버리기 (drop)

- 사용법: `버리기 <번호...>`, 번호 범위 `버리기 <a>-<b>`(예: `버리기 1-8`, ARC-010)
- 설명: 자료를 휴지통으로 옮긴다. 휴지통 자료는 30일 뒤 영구 삭제되고, 그 전에는 `되살리기 <번호>`로 돌린다. 1건은 바로 옮기고 2건 이상은 건수 확인 후 옮긴다(ARC-008). 휴지통 명령(`되살리기`, `휴지통`, `휴지통 비우기`)은 도움말 목록 2절에 있다
- 예: `버리기 131`

### 도움말 (guide)

- 사용법: `도움말`
- 설명: 명령 목록 표시. 자료가 0건이어도 `도움말`을 치면 전체 목록을 보여 준다. 자료가 없는 첫 화면은 이 목록 대신 `담기`·`찾기`·`넘기기` 세 명령과 샘플 안내를 보여 준다(US-6, 6절 첫 화면)

### 설명 (about)

- 사용법: `설명 <명령>`
- 설명: 명령 설명서 표시. 한글·영문 이름 모두 가능
- 예: `설명 찾기`, `about seek`

### 묶음 (pack)

- 사용법: `묶음`, `묶음 <이름>`, `묶음 <이름> 빼기 <번호...>`, `묶음 <이름> 지우기`
- 설명: 폴더 역할(한 단계, ARC-003). `묶음`은 묶음 목록. 선택이 있으면 `묶음 <이름>`이 선택한 자료를 넣고(없는 이름이면 새로 만듦), 선택이 없으면 묶음 안 자료를 보여 줌. `빼기`는 묶음에서만 빼고 `지우기`는 묶음만 지움(자료는 남음). 이후 `넘기기 <이름>`으로 같은 글 생성. 묶음 안 자료가 삭제되면 넘길 때 `빠진 자료 N건` 표시. 이름은 띄어쓰기 없이 1~20자
- 예: `묶음`, `묶음 결제조사`, `묶음 결제조사 빼기 140`

### 가져오기 (bring)

- 사용법: `가져오기` 뒤 북마크 파일을 끌어다 놓음
- 설명: 북마크 파일의 링크를 한 번에 저장. 저장 건수, 건너뜀 건수(이미 저장됨), 실패 링크 표시

### 로그아웃 (signout)

- 사용법: `로그아웃`, `로그아웃 모든기기`
- 설명: 이 기기에서 로그아웃. `모든기기`는 모든 기기와 AI 도구 연결을 끊음(다른 기기는 최대 1시간 뒤, ACC-002)
- 예: `로그아웃`, `signout 모든기기`

### 연결 (plug)

- 사용법: `연결`, `연결 끊기 <번호>`
- 설명: AI 도구 연결 주소와 안내, 지금 있는 연결 목록(번호, AI 도구 이름, 연결한 날, 마지막으로 읽은 날) 표시. `연결 끊기`는 확인을 받은 뒤 그 연결 하나를 끊는다(ACC-002). 연결한 AI 도구는 검색·읽기만 가능

## 4. 이어 쓰기

`|` 앞 명령의 결과를 뒤 명령에 넘긴다. 한글·영문을 섞어 써도 된다.

- `찾기 결제 | 넘기기`: 결과가 5건 이하이면 바로 복사한다. 6~10건이면 복사하지 않고 `전부`를 낱말로 받는다. 10건을 넘으면 `앞10`(앞 10건만), `전부`(N건 전부) 중 하나를 낱말로 받는다. 그 외 입력은 취소다(US-5, 2026-11-26 PO 결정). 숫자 선택지는 자료 번호(ARC-001)와 헷갈리므로 쓰지 않는다
- `seek 결제 | handoff`: 위와 같다

## 5. 틀리게 쳤을 때

- 없는 명령: `✗ 없는 명령: 찻기` 뒤에 `→ 명령 목록: 도움말`.
- 가까운 명령이 있으면 제안한다(F17): `찻기 결제` → `→ 찾기 결제?`
- 진짜 터미널 명령(2026-11-26 PO 결정): 같은 일을 하는 그렙 명령이 분명하면 받아서 실행하고 첫 줄에 알린다. `grep 결제` → `· grep → 찾기 결제로 실행` 뒤에 찾기 결과.

| 입력 | 실행 |
|---|---|
| `grep`, `find` | `찾기` |
| `ls` | `최근` |
| `help`, `man`, `?` | `도움말` |

- 되돌릴 수 없거나 뜻이 갈리는 명령(`rm`, `del`, `copy`, `cp`, `cd` 등)은 실행하지 않고 알려만 준다: `· rm 없음 → 버리기 131 (drop 131)`.
- 받아 주는 이름은 입력으로만 받는다. `도움말` 목록, 자동 완성 후보, `설명`에는 나오지 않는다.

입력 받아 주기(2026-11-26 PO 결정, 디자이너 검토 4절 ③):

| 상황 | 동작 |
|---|---|
| 가까운 명령 제안 `→ 찾기 결제?`가 떠 있음 | 그 상태에서 엔터 한 번이면 제안대로 실행한다. 다른 글자를 치면 제안은 사라진다 |
| 결과가 나온 직후 | 입력줄에 다음 명령을 흐리게 미리 띄운다(예: 찾기 뒤 `고르기`). Tab으로 받고, 그냥 치면 사라진다 |
| 영문 자판으로 한글 명령을 침 | 첫 낱말이 명령이 아니고 두벌식으로 바꾸면 명령이면 첫 낱말만 바꿔 실행하고 알린다. 뒤의 검색어는 친 그대로 둔다. `ckwrl onboarding` → `· ckwrl → 찾기 onboarding으로 실행` |
| 낱자 `ㅣ`를 이어 쓰기 자리에 침 | 앞뒤가 띄어 쓴 낱자 `ㅣ` 하나이면 `\|`로 받는다. `찾기 결제 ㅣ 넘기기` = `찾기 결제 \| 넘기기` |
| 입력 중 | 첫 낱말이 유효한 명령(받아 주는 이름 포함)일 때만 파란색. 엔터 전에 오타를 알 수 있다 |

## 6. 화면 문구

출력은 로그처럼 쓴다(PO 결정, 2026-11-25). 디자인 시스템 "그렙 터미널"의 문구 규칙과 같다.

| 규칙 | 예 | 쓰지 않는 것 |
|---|---|---|
| 상태는 `~됨`, `~ 중`, `없음`으로 끝낸다 | `✓ 저장됨`, `요약 생성 중`, `0건` | 저장했어요, 만드는 중이에요 |
| 구조는 `무엇: 값` 또는 `무엇  값` | `✗ 없는 명령: 찻기`, `✓ 복사됨  2건 · 442자` | 알 수 없는 명령이에요 |
| 숫자는 앞에, 단위는 `건`·`자` | `4건`, `23건 중 10건` | 4건을 찾았어요 |
| 이유는 괄호나 콜론 뒤 한 마디 | `! 본문 못 가져옴: 로그인 필요` | 로그인이 필요한 글이라 … |
| 다음에 칠 것은 `→` 뒤에 명령만. 명령 하나가 칩 하나이고, 누르면 입력줄에 찍히고 엔터로 실행한다. 명령이 아닌 화면 칩(`펼치기`)은 누르면 바로 동작한다(2026-11-26 PO 결정). 차례로 할 일은 줄을 나누고, 고를 수 있는 대안은 `또는`으로 잇는다. 밝기는 본문과 같다 | `→ 고르기 131 140` 다음 줄 `→ 넘기기 또는 묶음 <이름>` | 번호로 고르고 넘기기로 복사해요, `→ 고르기 131 140 · 넘기기`(`·`가 "그다음"인지 "또는"인지 모름) |
| 화면에 찍힌 명령·자료 번호·묶음 이름은 누를 수 있다. 누르면 그 명령이 입력줄에 찍힌다. 파란색은 "칠 수 있는 글자"다 | 목록의 `131`을 누르면 `고르기 131`, 제목을 누르면 `열기 131`이 찍힌다(ARC-011, 발표 뒤) | 사이드바, 모달, 상단 메뉴, 체크박스 표 |
| 예시는 `예:` 뒤에 | `✗ 검색어 없음  예: 찾기 결제` | 무엇을 찾을지 알려 주세요 |
| 확인 질문은 명령 이름 + `?` + 대상 | `버리기? 3건 (휴지통으로)` | 이 자료를 지울까요?, 삭제? |
| 확인 답은 숫자가 아니라 낱말로 받는다. 같은 명령 이름(한글·영문) 하나를 다시 치면 실행, 그 외 입력은 `· 취소됨` 뒤 그 명령을 실행(COM-007) | `→ 실행: 버리기 다시 입력 · 취소: 그 외 입력` | `1 취소 · 2 삭제` (숫자는 자료 번호, ARC-001) |

느낌표, 이모지, 감탄은 쓰지 않는다. 사용자를 탓하지 않는다. 기호: `✓` 성공, `·` 안내, `!` 알림(실패 아님), `✗` 실패.

| 상황 | 문구 |

| 저장 | `✓ 저장됨  카페 텀블러 할인, 올겨울 캠페인 늘었다 (팀 가상 기사)` 뒤에 `요약 생성 중` |

| 본문 못 가져옴 | `! 본문 못 가져옴: 로그인 필요  제목·링크만 저장` |
| 찾기 결과 | `4건`, `23건 중 10건`, 없으면 `· 0건: "검색어"` 뒤에 `· 최근 저장 3건 (검색 결과 아님)` 머리줄과 3건 |

## 7. 이름 겹침 확인

영문판 이름이 기존 명령과 겹치는지 2026-11-25에 확인했고, 2026-11-26에 13개와 휴지통 제안 이름(`revive`, `bin`)을 PowerShell 5.1과 Git Bash에서 다시 확인했다.

| 확인한 곳 | 방법 | 결과 |
|---|---|---|
| 윈도우 PowerShell 5.1 | `Get-Command`(명령, 별칭, 실행 파일) | 위 13개와 `revive`·`bin` 모두 없음. `peek`(열기), `gather`(찾아두기)도 2026-11-26에 따로 확인해 없음 |
| 윈도우 명령 프롬프트 | 내장 명령 목록과 대조 | 없음 |
| bash(Git Bash) | `type -t`(내장 명령과 PATH) | 없음(`peek`, `gather` 포함) |
| 맥 터미널(zsh) | 확인하지 못함 | 화면 시안 때 맥에서 `type <이름>`으로 확인 |

후보였다가 뺀 이름: `copy`·`help`·`find`(윈도우·리눅스 명령), `connect`(이 PC에 같은 이름의 프로그램이 있음), `bundle`(맥에 기본으로 들어 있는 Ruby 도구와 겹칠 수 있음), `stow`(널리 쓰는 GNU 도구), `edit`(윈도우 11의 편집기 명령), `open`(맥에서 파일을 여는 명령), `view`(vim 읽기 전용 모드, Git Bash에 있음), `watch`(리눅스 명령). 한글 `모으기`는 F20(작업 이름으로 모으기)과 헷갈려 쓰지 않는다.

## 8. 정하지 않은 것

- 명령을 버튼으로 누르는 방식(휴대폰 US-7): 모바일은 누르면 바로 실행하고 확인 질문은 낱말 버튼으로 답한다([MOB-002](../policies/mobile/MOB-002-tap-runs-command.md), 검토 중 PO 확인 대기). 웹은 5절대로 찍기만 한다.
- `더 보기`를 쳐서 부르는 방법(명령으로 둘지, 빈 입력에서 엔터로 할지)은 개발과 정한다. 지금은 누르는 칩으로만 둔다.
- 첫 화면의 `샘플 8건으로 해 보기`는 샘플 8건을 실제 자료로 저장하고 그 계정의 다음 번호 8개를 준다(새 계정은 1~8번). 완료 줄에 받은 범위와 치우는 명령(`버리기 <a>-<b>`)을 보인다(ARC-010, 2026-11-26 PO 결정).
- 웹에는 자세히 보기가 없다. 발표 뒤에 만든다(2026-11-26 PO 결정). 그때까지 웹에서 태그는 목록의 앞 3개만, AI 요약 이름표는 넘길 글 미리보기에서 보인다.
- 별칭(예: `찾` 한 글자)과 옵션 문법(예: `--본문`)은 두지 않는다. 필요하면 시안 검증 뒤 더한다. 시점(F22)도 옵션이 아니라 마지막 낱말로 받는다.
- 시점의 영문 표기(`3w`, `nov` 등)와 "대략"의 너비(예: `3주전`에 앞뒤 한 주를 더할지)는 화면 시안과 데모 리허설에서 정한다.
