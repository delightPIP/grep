# 명령어 설명서

- 작성일: 2026-11-25
- 상태: 제안. 명령 이름과 문법은 11/26 웹 화면 시안에서 PO가 확인한 뒤 확정한다
- 근거: [기획서](PRD.md) 8절, PO 결정(2026-11-25, [STATE](STATE.md) 12절)

그렙의 터미널 화면에서 쓰는 명령을 진짜 터미널의 설명서(`man` 페이지)처럼 정리한다. 화면의 `도움말`과 `설명 <명령>`은 이 문서의 내용을 그대로 보여 준다.

## 1. 원칙 (PO 결정)

1. **기본 명령은 한글이다.** 모든 명령에 영문판이 있고, 둘은 완전히 같은 일을 한다. 한 줄 안에서 섞어 써도 된다.
2. **기존 터미널·프롬프트의 명령 이름을 쓰지 않는다.** 영문판도 맥 터미널, 윈도우 명령 프롬프트, PowerShell, 리눅스 셸에 이미 있는 이름(`grep`, `ls`, `rm`, `cp`, `copy`, `find`, `help`, `man`, `cd` 등)과 겹치지 않게 고른다. 진짜 터미널에서 그렙의 명령을 쳐도 다른 명령이 실행되지 않게 하고, 반대로 사용자가 진짜 명령으로 착각하지 않게 하기 위해서다. 서비스 이름이 그렙(grep)이어도 `grep`을 명령으로 쓰지 않는다.
3. **진짜 터미널처럼 보이고 움직인다.** 프롬프트, 명령 한 줄, 결과 한 덩어리, 이어 쓰기(`|`), 명령별 설명서가 있다. 진짜 명령줄 도구는 아니다.

한글을 기본으로 하면 좋은 점: 한국어 검색어를 칠 때 한/영 전환 없이 `찾기 결제`처럼 한 번에 친다. 입문 사용자가 명령의 뜻을 바로 안다.

## 2. 명령 한눈에 보기

`도움말`(영문 `guide`)을 치면 나오는 화면이다.

```text
$ 도움말

  저장한 자료를 찾아 AI 도구에 넘기는 명령들이에요.
  링크·글은 붙여 넣고, 파일은 끌어다 놓으면 바로 저장돼요.

  담기     keep      자료 저장하기
  최근     recent    최근 저장한 자료 보기
  찾기     seek      단어로 자료 찾기
  고르기   pick      번호로 자료 고르기
  넘기기   handoff   고른 자료를 AI 도구에 붙여 넣을 글로 복사
  묶음     pack      고른 자료에 이름 붙여 두고 다시 쓰기
  고치기   revise    제목·요약 고치기
  버리기   drop      자료 지우기
  가져오기 bring     브라우저 북마크 파일 가져오기
  연결     plug      AI 도구가 아카이브를 직접 읽게 연결하기
  도움말   guide     이 목록 보기
  설명     about     명령 하나의 자세한 설명 보기

  예) 찾기 결제 | 넘기기
  자세히: 설명 찾기
```

| 한글 | 영문 | 기능 | 우선순위 |
|---|---|---|---|
| `담기` | `keep` | F1 | P0 |
| `최근` | `recent` | F3 | P0 |
| `찾기` | `seek` | F3 | P0 |
| `고르기` | `pick` | F4 | P0 |
| `넘기기` | `handoff` | F4 | P0 |
| `고치기` | `revise` | F14 | P0 |
| `버리기` | `drop` | F14 | P0 |
| `도움말` | `guide` | F5 | P0 |
| `설명` | `about` | F5 | P0 |
| `묶음` | `pack` | F12 | P1 |
| `가져오기` | `bring` | F8 | P1 |
| `연결` | `plug` | F7 | P1 |

## 3. 명령별 설명서

`설명 <명령>`(영문 `about <명령>`)을 치면 아래 형식으로 나온다.

### 담기 (keep)

- 사용법: `담기 <링크 또는 글>`
- 설명: 자료를 저장한다. 링크·글을 입력창에 붙여 넣거나 파일을 화면에 끌어다 놓으면 명령 없이도 저장된다. 이미 저장한 링크나 같은 파일이면 새로 만들지 않고 "이미 저장한 자료가 있어요"라고 알린 뒤 그 자료를 보여 준다(F21)
- 예: `담기 https://example.com/payments-guide`

### 최근 (recent)

- 사용법: `최근 [개수]`
- 설명: 최근 저장한 자료를 번호와 함께 보여 준다. 개수를 안 쓰면 10건
- 예: `최근`, `최근 20`

### 찾기 (seek)

- 사용법: `찾기 <검색어>`
- 설명: 제목·본문·요약·이미지 속 글자에 검색어가 들어 있는 자료를 최근 저장한 순서로 번호와 함께 보여 준다. 10건을 넘으면 앞의 10건과 전체 건수를 보여 준다
- 예: `찾기 결제`, `찾기 onboarding 화면`

### 고르기 (pick)

- 사용법: `고르기 <번호...>`
- 설명: 바로 앞 결과에서 번호로 자료를 고른다. 고른 자료는 넘기기·묶음의 대상이 된다
- 예: `고르기 1 3`

### 넘기기 (handoff)

- 사용법: `넘기기 [묶음 이름]`
- 설명: 고른 자료(또는 이름 붙인 묶음)를 AI 도구에 붙여 넣을 글로 복사한다. 몇 건을 몇 글자로 복사했는지 보여 준다. 넘길 글의 내용은 기획서 8절 정의를 따른다
- 예: `넘기기`, `넘기기 결제조사`

### 고치기 (revise)

- 사용법: `고치기 <번호>`
- 설명: 자료의 제목이나 요약을 고친다. 사용자가 고친 요약은 자동 요약이 덮어쓰지 않는다
- 예: `고치기 2`

### 버리기 (drop)

- 사용법: `버리기 <번호>`
- 설명: 지울 자료의 제목을 보여 주고 확인을 받은 뒤 지운다
- 예: `버리기 2`

### 도움말 (guide)

- 사용법: `도움말`
- 설명: 2절의 명령 목록을 보여 준다. 처음 들어와 자료가 없을 때도 이 목록이 나온다(US-6)

### 설명 (about)

- 사용법: `설명 <명령>`
- 설명: 명령 하나의 설명서(이 절의 내용)를 보여 준다. 한글·영문 어느 이름으로 물어도 된다
- 예: `설명 찾기`, `about seek`

### 묶음 (pack)

- 사용법: `묶음 <이름>`
- 설명: 고른 자료에 이름을 붙여 둔다. 나중에 `넘기기 <이름>`으로 같은 묶음을 다시 넘긴다. 묶음 안의 자료가 지워졌으면 넘길 때 빠진 자료가 있다고 알린다
- 예: `묶음 결제조사`

### 가져오기 (bring)

- 사용법: `가져오기` 뒤 북마크 파일을 끌어다 놓음
- 설명: 브라우저에서 내보낸 북마크 파일의 링크를 한 번에 저장한다. 저장한 건수, 건너뛴 건수(이미 저장한 링크), 실패한 링크를 보여 준다

### 연결 (plug)

- 사용법: `연결`
- 설명: AI 도구에 넣을 연결 주소와 안내를 보여 준다. 연결한 AI 도구는 아카이브를 검색하고 읽기만 한다

## 4. 이어 쓰기

`|` 앞 명령의 결과를 뒤 명령에 넘긴다. 한글·영문을 섞어 써도 된다.

- `찾기 결제 | 넘기기`: 결과가 5건 이하이면 바로 복사하고, 5건을 넘으면 목록을 보여 주며 그대로 넘길지 번호로 뺄지 묻는다(US-5)
- `seek 결제 | handoff`: 위와 같다

## 5. 틀리게 쳤을 때

- 없는 명령이면 "알 수 없는 명령이에요"라고 알리고 `도움말`을 안내한다.
- 가까운 명령이 있으면 제안한다(F17). 예: `찻기 결제` → "`찾기`를 말한 건가요?"
- 진짜 터미널 명령(`grep`, `ls`, `rm`, `copy` 등)을 치면 그렙의 어떤 명령에 해당하는지 알려 준다. 예: `grep 결제` → "이 화면에서는 `찾기 결제`(또는 `seek 결제`)로 찾아요"

## 6. 이름 겹침 확인

영문판 이름이 기존 명령과 겹치는지 2026-11-25에 확인했다.

| 확인한 곳 | 방법 | 결과 |
|---|---|---|
| 윈도우 PowerShell 5.1 | `Get-Command`(명령, 별칭, 실행 파일) | 위 12개 모두 없음 |
| 윈도우 명령 프롬프트 | 내장 명령 목록과 대조 | 없음 |
| bash(Git Bash) | `type -t`(내장 명령과 PATH) | 없음 |
| 맥 터미널(zsh) | 확인하지 못함 | 화면 시안 때 맥에서 `type <이름>`으로 확인 |

후보였다가 뺀 이름: `copy`·`help`·`find`(윈도우·리눅스 명령), `connect`(이 PC에 같은 이름의 프로그램이 있음), `bundle`(맥에 기본으로 들어 있는 Ruby 도구와 겹칠 수 있음), `stow`(널리 쓰는 GNU 도구), `edit`(윈도우 11의 편집기 명령).

## 7. 정하지 않은 것

- 명령을 버튼으로 누르는 방식(휴대폰 US-7)은 모바일 앱 단계에서 정한다.
- 별칭(예: `찾` 한 글자)과 옵션 문법(예: `--본문`)은 두지 않는다. 필요하면 시안 검증 뒤 더한다.
