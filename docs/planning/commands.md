# 명령어 설명서

- 작성일: 2026-11-25
- 상태: 제안. 명령 이름과 문법은 11/26 웹 화면 시안에서 PO가 확인한 뒤 확정한다
- 근거: [기획서](PRD.md) 8절, PO 결정(2026-11-25, [STATE](STATE.md) 12절)

그렙의 터미널 화면에서 쓰는 명령과 화면 문구를 진짜 터미널의 설명서(`man` 페이지)처럼 정리한다. 화면의 `도움말`과 `설명 <명령>`은 이 문서의 내용을 그대로 보여 준다. 화면 문구의 기준은 6절이다.

## 1. 원칙 (PO 결정)

1. **기본 명령은 한글이다.** 모든 명령에 영문판이 있고, 둘은 완전히 같은 일을 한다. 한 줄 안에서 섞어 써도 된다.
2. **기존 터미널·프롬프트의 명령 이름을 쓰지 않는다.** 영문판도 맥 터미널, 윈도우 명령 프롬프트, PowerShell, 리눅스 셸에 이미 있는 이름(`grep`, `ls`, `rm`, `cp`, `copy`, `find`, `help`, `man`, `cd` 등)과 겹치지 않게 고른다. 진짜 터미널에서 그렙의 명령을 쳐도 다른 명령이 실행되지 않게 하고, 반대로 사용자가 진짜 명령으로 착각하지 않게 하기 위해서다. 서비스 이름이 그렙(grep)이어도 `grep`을 명령으로 쓰지 않는다.
3. **진짜 터미널처럼 보이고 움직인다.** 프롬프트, 명령 한 줄, 결과 한 덩어리, 이어 쓰기(`|`), 명령별 설명서가 있다. 진짜 명령줄 도구는 아니다.
4. **문구는 진짜 터미널처럼 건조하게 쓴다.** 출력은 문장이 아니라 로그다. 해요체·반말 어미 없이 `저장됨`, `4건`, `없는 명령: 찻기`처럼 쓴다(6절).

한글을 기본으로 하면 좋은 점: 한국어 검색어를 칠 때 한/영 전환 없이 `찾기 결제`처럼 한 번에 친다. 입문 사용자가 명령의 뜻을 바로 안다.

## 2. 명령 한눈에 보기

`도움말`(영문 `guide`)을 치면 나오는 화면이다.

```text
그렙 ~ $ 도움말

  저장: 링크·글 붙여 넣기, 파일 끌어다 놓기. 명령: 한글·영문 같음

  담기     keep      자료 저장
  최근     recent    최근 자료 목록
  찾기     seek      검색
  고르기   pick      번호로 선택
  넘기기   handoff   AI 도구용 글 복사
  묶음     pack      선택에 이름 붙이기
  고치기   revise    제목·요약 수정
  버리기   drop      삭제
  가져오기 bring     북마크 파일 가져오기
  연결     plug      AI 도구 연결
  도움말   guide     명령 목록
  설명     about     명령 설명

  → 예: 찾기 결제 | 넘기기 · 자세히: 설명 찾기
```

|---|---|---|---|
| `담기` | `keep` | F1 | P0 |
| `최근` | `recent` | F3 | P0 |
| `찾기` | `seek` | F3 | P0 |
| `고르기` | `pick` | F4 | P0 |
| `넘기기` | `handoff` | F4 | P0 |
| `고치기` | `revise` | F14 | P0 |
| `버리기` | `drop` | F14 | P0 |
| `도움말` | `guide` | F5 | P0 |
| `설명` | `about` | F5 | P0 |

| `가져오기` | `bring` | F8 | P1 |

## 3. 명령별 설명서

`설명 <명령>`(영문 `about <명령>`)을 치면 아래 형식으로 나온다. 설명 줄은 화면에 그대로 나가는 문구다.

### 담기 (keep)

- 사용법: `담기 <링크 또는 글>`
- 설명: 자료 저장. 링크·글은 붙여 넣기만 해도 저장. 이미 저장된 링크·파일은 새로 만들지 않음(F21)
- 예: `담기 https://example.com/payments-guide`

### 최근 (recent)

- 사용법: `최근 [개수]`
- 설명: 최근 저장 자료 목록. 개수 생략 시 10건
- 예: `최근`, `최근 20`

### 찾기 (seek)

- 사용법: `찾기 <검색어>`
- 설명: 제목·본문·요약·이미지 속 글자에서 검색. 최근 저장 순. 10건 초과 시 앞 10건과 전체 건수
- 예: `찾기 결제`, `찾기 onboarding 화면`

### 고르기 (pick)

- 사용법: `고르기 <번호...>`
- 설명: 바로 앞 목록에서 번호로 선택. 선택한 자료는 넘기기·묶음 대상
- 예: `고르기 1 3`

### 넘기기 (handoff)

- 사용법: `넘기기 [묶음 이름]`
- 설명: 선택한 자료 또는 묶음을 AI 도구용 글로 복사. 자료마다 제목 · 출처 · 저장 시각 · 요약. 넘길 글의 내용은 기획서 8절 정의를 따른다
- 예: `넘기기`, `넘기기 결제조사`

### 고치기 (revise)

- 사용법: `고치기 <번호>`
- 설명: 제목·요약 수정. 직접 고친 요약은 자동 요약이 덮어쓰지 않음
- 예: `고치기 2`

### 버리기 (drop)

- 사용법: `버리기 <번호>`
- 설명: 자료 삭제. 제목 확인 후 삭제
- 예: `버리기 2`

### 도움말 (guide)

- 사용법: `도움말`
- 설명: 명령 목록 표시. 자료가 없는 첫 화면에도 표시(US-6)

### 설명 (about)

- 사용법: `설명 <명령>`
- 설명: 명령 설명서 표시. 한글·영문 이름 모두 가능
- 예: `설명 찾기`, `about seek`

### 묶음 (pack)

- 사용법: `묶음 <이름>`
- 설명: 선택한 자료에 이름 붙이기. 이후 `넘기기 <이름>`으로 같은 글 생성. 묶음 안 자료가 삭제되면 넘길 때 `빠진 자료 N건` 표시
- 예: `묶음 결제조사`

### 가져오기 (bring)

- 사용법: `가져오기` 뒤 북마크 파일을 끌어다 놓음
- 설명: 북마크 파일의 링크를 한 번에 저장. 저장 건수, 건너뜀 건수(이미 저장됨), 실패 링크 표시

### 연결 (plug)

- 사용법: `연결`
- 설명: AI 도구 연결 주소와 안내 표시. 연결한 AI 도구는 검색·읽기만 가능

## 4. 이어 쓰기

`|` 앞 명령의 결과를 뒤 명령에 넘긴다. 한글·영문을 섞어 써도 된다.

- `찾기 결제 | 넘기기`: 결과가 5건 이하이면 바로 복사하고, 5건을 넘으면 복사하지 않고 `선택: 1 앞 10건만 · 2 N건 전부 · 3 취소`를 묻는다(US-5)
- `seek 결제 | handoff`: 위와 같다

## 5. 틀리게 쳤을 때

- 없는 명령: `✗ 없는 명령: 찻기` 뒤에 `→ 명령 목록: 도움말`.
- 가까운 명령이 있으면 제안한다(F17): `찻기 결제` → `→ 찾기 결제?`
- 진짜 터미널 명령(`grep`, `ls`, `rm`, `copy` 등): 같은 일을 하는 그렙 명령을 알려 준다. `grep 결제` → `· grep 없음 → 찾기 결제 (seek 결제)`

## 6. 화면 문구

출력은 로그처럼 쓴다(PO 결정, 2026-11-25). 디자인 시스템 "그렙 터미널"의 문구 규칙과 같다.

| 규칙 | 예 | 쓰지 않는 것 |
|---|---|---|
| 상태는 `~됨`, `~ 중`, `없음`으로 끝낸다 | `✓ 저장됨`, `요약 생성 중`, `0건` | 저장했어요, 만드는 중이에요 |
| 구조는 `무엇: 값` 또는 `무엇  값` | `✗ 없는 명령: 찻기`, `✓ 복사됨  2건 · 1,240자` | 알 수 없는 명령이에요 |
| 숫자는 앞에, 단위는 `건`·`자` | `4건`, `23건 중 10건` | 4건을 찾았어요 |
| 이유는 괄호나 콜론 뒤 한 마디 | `! 본문 못 가져옴: 로그인 필요` | 로그인이 필요한 글이라 … |
| 다음에 칠 것은 `→` 뒤에 명령만 | `→ 고르기 1 3 · 넘기기` | 번호로 고르고 넘기기로 복사해요 |
| 예시는 `예:` 뒤에 | `✗ 검색어 없음  예: 찾기 결제` | 무엇을 찾을지 알려 주세요 |
| 확인 질문은 `동사?` + 대상 | `삭제? PG사 수수료 비교 정리.pdf (되돌릴 수 없음)` | 이 자료를 지울까요? |

느낌표, 이모지, 감탄은 쓰지 않는다. 사용자를 탓하지 않는다. 기호: `✓` 성공, `·` 안내, `!` 알림(실패 아님), `✗` 실패.

주요 문구:

| 상황 | 문구 |
|---|---|
| 저장 | `✓ 저장됨  결제위젯 연동 가이드 (docs.tosspayments.com)` 뒤에 `요약 생성 중` |
| 글 저장 | `✓ 저장됨 (글)  <앞 24자>` |
| 이미 저장된 자료(F21) | `! 이미 저장됨 → 1번 (새로 만들지 않음)` 뒤에 그 자료 한 줄과 `→ 고르기 1` |
| 본문 못 가져옴 | `! 본문 못 가져옴: 로그인 필요  제목·링크만 저장` |
| 찾기 결과 | `4건`, `23건 중 10건`, 없으면 `· 0건: "검색어"` 뒤에 최근 저장 3건 |
| 고르기 | `✓ 2건 선택` 뒤에 칩과 `→ 넘기기 · 묶음 <이름>` |
| 넘기기 | `✓ 복사됨  2건 · 1,240자` 뒤에 `→ AI 도구 입력창에 붙여 넣기` |
| 5건 초과 이어 쓰기 | `! 23건: 바로 복사 안 함 (5건 초과)` 뒤에 `선택: 1 앞 10건만 · 2 23건 전부 · 3 취소` |
| 묶음 | `✓ 묶음 결제조사: 2건` 뒤에 `→ 다음부터: 넘기기 결제조사` |
| 묶음 안 자료 삭제됨 | `! 빠진 자료 1건 (삭제됨)` |
| 지우기 확인 | `삭제? <제목> (되돌릴 수 없음)` 선택 `1 취소 · 2 삭제` |
| 지움 | `✓ 삭제됨  <제목>` |
| 빠진 인자 | `✗ 검색어 없음`, `✗ 선택한 자료 없음`, `✗ 묶음 이름 없음`, `✗ 번호 없음` 뒤에 `예: …` |
| 없는 번호 | `✗ 없는 번호  범위: 1~4` |
| 목록 없이 고르기 | `✗ 목록 없음  먼저: 찾기 또는 최근` |
| 상태줄 | `자료 131 · 선택 2 · 묶음 결제조사 · 요약 생성 중 1` |
| 입력줄 안내 | `명령 입력 또는 링크 붙여 넣기` |
| 끌어다 놓기 | `놓으면 저장` / `링크 · 글 · 이미지 · PDF` |

## 7. 이름 겹침 확인

영문판 이름이 기존 명령과 겹치는지 2026-11-25에 확인했다.

| 확인한 곳 | 방법 | 결과 |
|---|---|---|
| 윈도우 PowerShell 5.1 | `Get-Command`(명령, 별칭, 실행 파일) | 위 12개 모두 없음 |
| 윈도우 명령 프롬프트 | 내장 명령 목록과 대조 | 없음 |
| bash(Git Bash) | `type -t`(내장 명령과 PATH) | 없음 |
| 맥 터미널(zsh) | 확인하지 못함 | 화면 시안 때 맥에서 `type <이름>`으로 확인 |

후보였다가 뺀 이름: `copy`·`help`·`find`(윈도우·리눅스 명령), `connect`(이 PC에 같은 이름의 프로그램이 있음), `bundle`(맥에 기본으로 들어 있는 Ruby 도구와 겹칠 수 있음), `stow`(널리 쓰는 GNU 도구), `edit`(윈도우 11의 편집기 명령).

## 8. 정하지 않은 것

- 명령을 버튼으로 누르는 방식(휴대폰 US-7)은 모바일 앱 단계에서 정한다.
- 별칭(예: `찾` 한 글자)과 옵션 문법(예: `--본문`)은 두지 않는다. 필요하면 시안 검증 뒤 더한다.
