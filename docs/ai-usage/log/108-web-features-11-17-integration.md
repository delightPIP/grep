## AI의 오류와 정정

1. 계약 2에서 처리 워커가 읽은 본문을 저장하지 않는다는 점을 놓쳐 V5가 갈래 중에 더해졌다.
2. 남은 피처를 이슈로 나눌 때 PRD 문장으로만 있는 기능(공유로 저장, 명령 버튼 등)을 빠뜨렸다. 사용자 질문으로 찾았고, 보강하면서 Android 기본 화면 이슈(#161)를 이미 끝난 #159와 중복으로 올려 닫았다.
3. 뜻 찾기 거리를 Windows 셸에서 한글을 curl로 보내 깨진 채로 재고 "기준을 못 넘는다"고 잘못 보고했다. W1이 다시 재 반박했고, UTF-8로 다시 재 정정했다. 화면에 안 나온 실제 원인은 M에 `related` 전달이 빠진 것이었다.
4. 가져온 자료의 요약 미루기(ADR-BCK-008 결정 2)를 화면 표시만 고치려 했다. 사용자가 "저장하면 알아서 요약"이라는 의도와 어긋난다고 짚어 처리 방식을 바꿨다.
5. W1이 M의 폴더(`core/`)에 #154 절반을 넣어 중복 구현이 생겼다. 통합 때 하나로 정리했다.
