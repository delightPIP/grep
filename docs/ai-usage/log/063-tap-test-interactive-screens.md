# 2026-11-26 · 부품으로 바꾼 화면 눌러 보기

- 작성자: TAENI
- 이슈·PR: #25
- 커밋: 없음(커밋 전)

> **요약** PO가 부품으로 바꾼 화면의 누르는 동작을 실제로 눌러 확인해 달라고 했다. AI가 시안의 재생(Play) 모드에서 눌러 볼 수 있는 화면 8장(M1·M3·M5·M6, 웹 09·10, D5)을 차례로 눌렀다. 부품을 통한 동작은 모두 됐다. 10 보관함 사이드바의 묶음을 누르면 기록 줄만 남고 목록은 바뀌지 않던 것을 찾아 고쳤다.

## 사용 도구

Claude Code(Opus 5.5). 내장 브라우저(시안 재생 모드에서 클릭), 시안 캔버스(Artifact), `Scripts/check-docs.sh`

## 요청

- 누르는 동작도 눌러서 확인해 달라.

## AI 산출물

- 눌러 본 결과(모두 됨)
  - M1: 알겠음(UiButton) → 안내 카드 사라짐
  - M3: 줄 누름(MList) → 고르기, ⋯ → 줄 메뉴 시트(MSheet) → 고르기, 칩 ×(MPickBar) → 빼기, 공유 n건 → 출력 줄, 모두 해제 → 고른 것 줄 대신 명령 줄과 탭이 다시 나옴
  - M5: 복사 → "복사됨", 공유 → OS 공유 시트(MOsShareSheet) 열림, 바깥 누름 → 닫힘
  - M6: 묶음 칩(UiButton quiet) → 목록, 체크 → 고른 것 줄(요약형), 해제, 줄 누름 → 자세히 보기(ItemDetailPanel), 고르기, ‹ 목록(MTopBar), ‹ 보관함
  - 09: 펼치기 → 본문 열림, 접기로 바뀜(ItemDetail)
  - 10: 지우기 → 확인 줄 → 취소(UiButton), 줄 누름 → 자세히 보기 칸, 고르기 → 선택에서 빼기로 바뀜, × → 닫힘, 모두 해제, 날짜 칩 → 목록, ‹ 보관함
  - D5: 끌어 오기 → 놓는 곳(DDropHint·점선 칸), 놓기·저장 → 저장 카드, 두더지 누름 → 빠른 창
- 고침: 10 보관함 사이드바 묶음(WSidebar onBundle)을 누르면 "묶음: 겨울캠페인" 목록으로 바뀌게 함(시안 버전 59)

## 사람의 판단

- 누르는 동작까지 확인하라고 정했다.

## 검증

- 위 동작을 내장 브라우저에서 한 번씩 누르고 화면이 바뀐 것을 스크린숏으로 확인했다.
- 고친 뒤 10을 다시 재생해 묶음을 누르면 목록이 "묶음: 겨울캠페인 2건"으로 바뀌는 것을 확인했다.
- `bash Scripts/check-docs.sh`: 통과

## 검증하지 못한 것

1. 누르면 아무 일도 없는 곳: M3·M6의 명령 버튼 4칸과 하단 탭, M5의 낱말 선택지(앞10 · 전부 · 취소), 10 사이드바의 터미널·설정. 이 시안에서는 동작을 연결하지 않은 표시용이다(M5 선택지는 부품으로 바꾸기 전에도 동작이 없었다). 연결할지는 PO가 정한다.
2. M4·28·D1~D4·D6~D11은 재생 표시(is_interactive)가 없는 정지 화면이라 누르지 않았다.
3. 끌어다 놓기 자체(D5의 파일을 실제로 끌기)는 해 보지 않았고, 같은 상태를 만드는 버튼으로만 확인했다.
4. 캔버스 축소 상태에서는 보드 안 클릭이 전달되지 않는다. 재생 모드(전체 화면)에서만 눌러진다.
