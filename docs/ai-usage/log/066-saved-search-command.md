# 2026-11-26 · 저장한 찾기 명령과 화면 (찾아두기)

> **요약** PO가 저장한 찾기의 명령과 화면도 정해 달라고 했고, AI가 명령 `찾아두기`(gather), 문법, 문구, 보관함 버튼을 정해 정책 ARC-012로 쓰고 시안을 그렸다. 이름·문법·문구는 AI 제안이고 PO 확인 전이다.

## 사용 도구

Claude Code(Opus 5.5), Artifact(디자인 캔버스 "그렙 웹 화면 시안"), `Scripts/check-docs.sh`, PowerShell `Get-Command`·bash `type -t`

## 요청

- 저장한 찾기 명령이랑 화면도 정해 달라.

## AI 산출물

- [ARC-012](../../policies/archive/ARC-012-saved-search.md)(검토 중): `찾아두기 <검색어>`로 저장하고 결과 보기, 이름은 검색어 그대로, 같은 검색어는 하나, 시점으로 끝나는 검색어는 저장하지 않음, 0건도 저장, `찾아두기`만 치면 목록, `찾아두기 <검색어> 지우기`는 확인 뒤 지움. 보관함 찾기 칸 결과에 `이 찾기 저장`, 저장한 찾기를 열면 `지우기`
- 명령어 설명서(도움말 목록, 설명서, 문구, 이름 겹침), 사용자 흐름도 12-2절, ARC-007 비고 연결, 자료 영역 열린 질문(상한에 저장한 찾기 수 더함)
- 시안: 웹 10에 찾기 칸 저장·지우기 확인, 새 화면 11(터미널 `찾아두기`)

## 사람의 판단

- 이름·문법·문구는 PO가 아직 확인하지 않았다.

## 검증

- `bash Scripts/check-docs.sh`: 통과
- `gather`는 PowerShell 5.1과 Git Bash에서 기존 명령이 아님을 확인
- 시안은 게시만 했고 열어 보지 않음

## 검증하지 못한 것

1. 맥 zsh에서 `gather` 이름 겹침
2. 시안의 찾기 칸 입력·엔터·저장·지우기 동작

## AI의 오류와 정정

1. 처음 떠올린 한글 이름 `모으기`는 기획서 F20(작업 이름으로 모으기)이 이미 쓰는 말이라 `찾아두기`로 바꿨다.
2. 시안을 올리기 전 다른 세션이 캔버스를 고친 판이 있어, 그 판의 색인과 모바일 M3 파일을 받아 그 위에 이번 변경만 얹었다.
