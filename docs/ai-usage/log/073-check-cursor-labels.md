# 2026-11-26 · 바뀐 `_` 버튼을 시안에서 열어 보기

- 작성자: TAENI
- 이슈·PR: #30
- 커밋: 없음(커밋 전)

> **요약** PO가 `_`로 바꾼 버튼을 시안에서 열어 확인해 달라고 했다. AI가 재생 모드에서 M2·M3·웹 10을 열었다. 버튼은 모두 제대로 보였다. M2 설명 줄이 길어져 "명령 전체" 제목이 두 줄로 깨진 것을 찾아 고쳤다.

## 사용 도구

Claude Code(Opus 5.5). 내장 브라우저(재생 모드), 시안 캔버스(Artifact)

## 요청

- 시안에서 바뀐 버튼 열어서 확인해 줘.

## AI 산출물

- 확인: M2 명령 설명판(`찾기 _ · 고르기 _ · 묶음 _`), M3 명령 버튼(`찾기 _ · 고르기 _`)과 고른 것 줄(`묶음 _`), M3 더보기 시트(`묶음 _ · 버리기 _`), 웹 10 선택 줄과 자세히 보기 칸(`묶음 _`)
- 고침(시안 버전 64·65): M2 설명 줄을 "_ 붙은 것은 이어 치기"에서 "_ 는 이어 치기"로 줄이고 제목이 줄바꿈되지 않게 함, M3 더보기 시트 설명도 같은 말로 맞춤

## 사람의 판단

- 시안에서 열어 확인하라고 정했다.

## 검증

- 고친 뒤 M2를 다시 열어 "명령 전체" 제목과 설명이 한 줄인 것을 확인했다.

## 검증하지 못한 것

1. M1·M6·M8·M9·M12·I1은 이번에 열어 보지 않았다. 같은 부품(MCommandBar·MPickBar)이라 글자만 바뀌었다.
