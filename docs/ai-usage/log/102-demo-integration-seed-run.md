## AI의 오류와 정정

1. 워크트리 정리 때 `git status`만 보고 `59-worker` 폴더를 지워, 사용자가 넣은 `server/.env`(Gemini 키)를 잃었다. 무시된 파일을 확인하지 않은 탓이다. 키를 다시 받아 메인 체크아웃에 두었고, 앞으로 무시 파일을 먼저 확인한다.
2. 원격 브랜치 정리 때 다른 계정(delightPIP)이 만든 브랜치 27개도 지웠다. 내용은 모두 머지·닫힌 PR이라 남아 있고, PR 페이지에서 되살릴 수 있다. 앞으로 자기 계정 브랜치만 지운다.
3. AI 도구 장면을 설명할 때 어디에 붙여 넣는지 분명히 하지 않아, 사용자가 그렙에 `담기`로 넣어 계정 B에 자료 2건이 생겼다. 계정 B를 초기화하고 시드를 다시 넣었다.
4. 시드 도구 작성 시 `SpringApplicationBuilder.properties`가 기본값이라 env의 `PORT`에 진다는 점, 버킷의 허용 형식을 놓쳤다(W2 갈래 산출물). 실제 실행에서 드러나 고쳤다.
