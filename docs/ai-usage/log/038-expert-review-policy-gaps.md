> **요약** AI가 서비스 전체 구조에서 빠진 정책을 검토하고, 서비스를 모르는 전문가에게 보낼 검토 프롬프트를 썼다. PO가 받아 온 외부 답변 3건(네 번째는 두 번째와 같은 글)을 AI가 대조해 발표 전 확정 후보와 다음 단계로 나눴고, PO가 그중 세 가지를 확정했다. 나머지는 열린 질문으로 넘겼다.

## 사용 도구

Claude Code(Opus 5.5), `docs:policy-manager` 스킬, `Scripts/check-docs.sh`. 외부 답변은 PO가 다른 AI 도구에서 받아 왔다.

## 요청

서비스 전체 구조에서 빠진 정책을 검토하고, 서비스를 모르는 전문가에게 물을 프롬프트를 달라는 요청. 이어서 외부 답변은 다 받아들이지 말고 첨언으로 보라는 지시.

## AI 산출물

- 빠진 정책 18개 목록(데모 관련, 공개 출시 전, 운영·비용)
- 외부 전문가용 검토 프롬프트(우리 검토 결과는 일부러 빼서 답이 거기에 맞춰지지 않게 함)
- 외부 답변 대조표: 공통 지적, 갈리는 값, 우리 정책을 잘못 읽은 지적, 개발 확인 항목
- 정책: ACC-001 수정, ARC-002 수정, ARC-004·005·006 새로 등록
- 열린 질문 추가(공통·계정·자료), 기존 열린 질문에 전문가 권장 범위 덧붙임
- 넘길 글 형식의 요약 칸 이름(`AI 요약`)과 안내 줄, 사용자 흐름도의 계정·`failed` 문구

## 사람의 판단

- 외부 답변은 첨언일 뿐 전부 받아들이지 않는다
- 발표 전 확정: ACC-001 수정(같은 이메일 자동 합치기 없앰, 세션 미사용 30일·최대 90일), AI 생성 표시와 민감정보 추론 태그 금지, 저장과 AI 처리 분리 및 서버가 여는 링크 범위
- 데모 원칙(전용 계정·샘플 자료만)은 지금 정책으로 두지 않음
- 보안 값(재시도, 시간·크기 상한, 막을 주소)은 개발자 판단

## 검증

`bash Scripts/check-docs.sh` 통과. 외부 답변이 인용한 법 조항과 링크는 원문과 대조하지 않았다.

## 검증하지 못한 것

1. 네 번째로 받은 답변이 두 번째 답변과 같아, 실제로는 3건만 대조했다.
2. 외부 답변의 법령 인용(개인정보 보호법 제28조의8, 인공지능기본법 등)은 확인하지 않았다. 정책 근거로 쓸 때 원문을 확인해야 한다.

## AI의 오류와 정정

1. 새 공통 정책을 COM-003으로 내면 열린 PR #8과 번호가 겹쳐, 자료 영역(ARC-004~006)에 두었다.
