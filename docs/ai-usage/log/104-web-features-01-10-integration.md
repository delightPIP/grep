## AI의 오류와 정정

1. 이슈를 올리기 전에 올릴 내용을 먼저 보여 주지 않았고, #149 계약 PR과 #111 댓글을 허락 없이 올렸다. 사용자 지적 뒤 게시 전 허락을 받는 규칙으로 바꿨다.
2. 계약을 한 번에 고정했다고 했지만 화면 문구를 다 대조하지 못해 갈래 중 W2가 빠진 값 4건을 찾아냈다. 갈래 브랜치에서 승인하고 M에 전달했다.
3. 계약 초안에 `POST /sessions/revoke-all`을 넣었다가 ACC-002 값 표("즉시 끊기는 두지 않는다")와 어긋나 뺐다.
4. #89에서 시드 도구가 `main`을 하나 더 만든 뒤 `bootRun`·`bootJar`가 실패하고 있었는데, 그때 CI가 테스트만 돌려 놓쳤다. 통합 서버를 띄우다 드러나 실행 클래스를 지정했다.
5. 샘플 목록 커밋(7eb2c9c)이 W1의 강제 푸시로 덮어써졌다. W1이 같은 내용으로 다시 넣었고 통합 때 내용을 대조했다.
6. 실측 안내 표에 명령 두 개를 쉼표로 붙여 적어 사용자가 한 줄로 입력했다.
7. 08 5절을 채울 때 같은 `| T-NN |`로 시작하는 4절 표까지 덮어썼다가 커밋 전에 되돌렸다(#148).
