# 2026-11-26 · 빠졌던 화면을 플랫폼별로 모두 그리기

- 작성자: TAENI
- 이슈·PR: #25
- 커밋: 없음(커밋 전)

> **요약** PO가 흐름 점검표에서 뽑은 빠진 화면을 하나도 빠짐없이, 체크리스트를 만들어 하나씩 확인하며 모든 플랫폼에 그려 달라고 했다. AI가 웹·모바일·iOS·데스크톱 체크리스트(60줄)를 만들고, 다른 작업이 먼저 그린 4개를 빼고 새 아트보드 30개를 시안 캔버스에 그린 뒤 브라우저로 열어 확인했다. 정책이 없는 문구·동작 14묶음은 제안으로 표시해 PO 확인을 남겼다.

## 사용 도구

Claude Code(Opus 5.5). 시안 캔버스(Artifact, 디자인 시스템 "그렙 터미널" 컴포넌트), Python 생성 스크립트 3개(웹 터미널형·모바일·데스크톱), Node(스크립트 구문 검사), 내장 브라우저(캔버스 확인), `Scripts/check-docs.sh`, `Scripts/check-stage-sensors.sh`

## 요청

- 빠졌던 화면을 하나도 빠짐없이 그려 달라. 체크리스트를 만든 뒤 하나하나 확인하면서 구성하고, 모든 플랫폼별 사용자 흐름 화면이 다 있으면 좋겠다.

## AI 산출물

- [플랫폼별 화면 체크리스트](../../planning/screen-checklist.md): 웹 W1~W34, 모바일·iOS M1~M16, 데스크톱 D1~D10. 시안 번호, 근거 정책, 흐름 점검표 항목, 확인 결과. 그리지 않는 것과 확인이 필요한 제안 14묶음
- 시안 캔버스 새 아트보드 30개: 웹 12~28(로그인, 로그아웃과 계정 전환, 도움말, 샘플, 저장 안 될 때, 처리, 시점·태그 찾기, 넘기기 상태, 고치기, 휴지통, 묶음, 연결, 연결 승인, 북마크 가져오기, 설정, 연결 끊김, 아이콘 레일), 모바일 M7~M12와 I1(로그인, 설치·올리기, 줄 메뉴 시트, 설정 탭, 휴지통, 넘기기·오프라인, iOS 공유 시트 상태), 데스크톱 D6~D11(설치, 첫 로그인, 트레이, 설정 창, 복사 링크 알림, 놓기 오류). 페이지 제목 메모 3개와 그리기 규칙 메모
- [흐름 점검표](../../planning/flow-inventory.md) 7절에 체크리스트 링크

## 사람의 판단

- 빠짐없이 모든 플랫폼에, 체크리스트를 먼저 만들고 하나씩 확인하라고 했다.
- 제안으로 그린 문구·동작(체크리스트 10절)은 PO가 아직 보지 않았다.

## 검증

- 아트보드마다 스크립트 구문(Node)과 태그 짝(Python)을 검사했다.
- 내장 브라우저로 캔버스를 열어 세 페이지를 축소해 새 아트보드 30개가 모두 그려지는지 봤고, 12·16·19·26·28·M7·M9·D7·D11은 확대해 읽었다.
- `bash Scripts/check-docs.sh`: 통과. `bash Scripts/check-stage-sensors.sh`: 통과(위반 0건)

## 검증하지 못한 것

1. 나머지 아트보드는 축소 화면에서 그려진 것만 확인했다. 글자 겹침이나 잘림이 남아 있을 수 있다.
2. 정적 시안이라 눌러서 바뀌는 동작은 없다.

## AI의 오류와 정정

1. 디자인 시스템의 결과 목록 컴포넌트를 휴대폰 폭에 그대로 썼더니 제목이 한 글자로 줄었다(M9). 기존 M3처럼 휴대폰용 두 줄 행으로 바꿨다.
2. 28 아이콘 레일의 두 칸이 페이지 폭에서 줄바꿈돼 아래 칸이 잘렸다. 칸 폭을 줄이고 아트보드 높이를 늘렸다.
3. 체크리스트가 다른 PR에만 있는 정책 번호(ARC-011, ARC-012)를 가리켜 문서 검사가 막았다. 번호 대신 "다른 PR의 정책 초안"으로 고쳤다.

4. 그리는 사이 main에 들어온 PR #27이 "도움말은 자료 0건이어도 전체 13줄"로 정했다. 시안 14 ①을 세 명령으로 그렸던 것을 전체 목록으로 고치고 체크리스트·흐름 점검표를 맞췄다.

## 발견 사항

1. 다른 작업이 같은 캔버스에 자세히 보기·보관함·저장한 찾기 화면을 그리는 중이었다. 겹치지 않게 그 4개는 체크리스트에서 "있음"으로 세고 새로 그리지 않았다.
