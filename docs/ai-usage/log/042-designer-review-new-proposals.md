> **요약** 디자이너 시안 검토(로그 041)의 4절 새 제안을 PO가 모두 반영하기로 해서, AI가 명령어 설명서·사용자 흐름도·ARC-005·ARC-003 문구와 디자인 시스템에 옮길 화면 규칙을 적었다. 디자인 시스템 아티팩트와 시안은 아직 고치지 않았다.

## 사용 도구

Claude Code(Opus 5.5), `docs:policy-manager` 스킬, `Scripts/check-docs.sh`

## 요청

검토 문서 4절 새 제안도 추천대로 반영해 달라는 요청.

## AI 산출물

- 명령어 설명서: 찾기 목록 두 줄 행과 `더 보기`, 입력 받아 주기 표(오타 제안 엔터, 흐린 다음 명령 Tab, 영문 자판 한글 명령, 낱자 `ㅣ`, 유효 명령만 파란색), 다음 명령 칩 규칙, 누를 수 있는 화면 글자 규칙, 고르기·넘기기·첫 화면·목록 꼬리표·더 보기 문구
- 사용자 흐름도 고르기·넘기기 단계
- ARC-005 처리 중 회색 `·`와 목록의 `! 본문 못 가져옴 → 고치기 <번호>`, ARC-003 묶음 0개 안내 줄 나눔
- 검토 문서 4-1절 디자인 시스템에 옮길 화면 규칙, STATE 결정 로그

## 사람의 판단

- 4절 새 제안을 모두 반영한다(PO)

## 검증

`bash Scripts/check-docs.sh` 통과

## 검증하지 못한 것

1. 디자인 시스템 "그렙 터미널"과 웹 시안에 규칙을 옮기지 않아, 화면에서 맞는지 보지 못했다.
2. `더 보기`를 쳐서 부르는 방법과 영문 자판 한글 명령 변환은 구현 가능성을 개발과 확인하지 않았다.
