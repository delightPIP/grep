> **요약** 라운드 4 W2 갈래(Windows)로 웹 로그인 뒤 화면을 폭별 사이드바·아이콘 레일·하단 탭(COM-011)으로 나누고, 보관함·설정 화면과 테마 줄(COM-012), 선택 줄 종류 낱말(ARC-003 규칙 14)을 순수 뷰로 만들었다. 계약 타입은 M 갈래가 `view-state.ts`에 넣기 전이라 갈래 폴더의 `contract.ts`에 임시로 두었다. 사람은 핸드오프대로 진행하라고 지시하고, 결과를 보고 로그와 푸시를 승인했다.

## 사용 도구

Claude Code(Opus 5.5), Node·Vitest(jsdom), `gh` CLI, 스킬 `core-dev:commit-rules`, `docs:ai-usage`.

## 요청

`.handoff-latest.md`(W2 갈래 핸드오프)를 읽고 그대로 진행할 것을 요청했다. 작업 뒤 "문제없으면 로그남기고 푸시해"라고 지시했다.

## AI 산출물

- `web/features/logged-in/view.tsx`를 `terminal.tsx`(터미널 화면, `TerminalScreen`)로 옮기고, 새 `view.tsx`는 세 화면을 늘 붙여 두는 셸(`LoggedInView`)로 만들었다. 어댑터·기존 테스트의 import는 그대로다.
- `layout.ts`(1008px·600px 경계, 창 크기 따라가기), `nav.tsx`(사이드바·레일·하단 탭, 배지 없음), `archive.tsx`(구역 차례 묶음 → 저장한 찾기 → 형식·출처·날짜·태그, 목록 행 재사용, 넓은 폭 오른쪽 칸·좁은 폭 새 화면 자세히 보기, 불러오는 중·실패·더 보기), `settings.tsx`(계정 · AI 도구 연결 · 휴지통 · 화면(테마) · 로그아웃), `pick-word.ts`(`PDF 25 · 글 12 · example.com 3`), `contract.ts`(임시 계약 타입)
- `web/styles/grep.css` 배치·보관함·설정 스타일
- 테스트: `screens.test.tsx`(599·600·1007·1008px 경계, 폭이 바뀌어도 화면·치던 글·선택 유지, 하단 탭 숨김, 보관함·설정·테마 줄), `ui/theme.test.ts`(고른 테마가 시스템 설정을 이기는지, 두더지 색이 테마 토큰을 쓰지 않는지), `view.test.tsx`(선택 줄 낱말)
- AI가 정한 동작(정책에 없는 부분, 코드에 `shortcut:` 주석):
  - 보관함에는 입력줄이 없어 제목·번호를 누르면 `열기 N`·`고르기 N`을 찍지 않고 바로 실행하고, 치던 글을 되돌린다.
  - 자세히 보기의 동작 칩과 설정의 끊기·휴지통·로그아웃은 확인 줄이 뜨는 터미널로 옮겨 처리한다.
  - 하단 탭의 "입력 중" 숨김은 터치 기기에서만 한다(마우스 기기의 좁은 창은 입력줄에 늘 초점이 있어 탭이 사라지므로).
  - `전체`, `· 불러오는 중`, `불러오기 안 됨`, `다시 시도`, 설정 줄 설명은 iOS 문구를 따르거나 AI가 붙인 문구다.

## 사람의 판단

- 핸드오프 순서대로 진행하도록 지시했다.
- 결과 보고(판단한 부분과 통합 세션 전달 사항 포함)를 보고 로그 작성과 푸시를 승인했다. AI가 정한 동작·문구는 통합·PO 확인으로 남겼다.

## 검증

- `npx vitest run`: 11개 파일 335건 통과(작업 전 303건).
- `npx tsc --noEmit`: 새 타입 오류 없음. 작업 전부터 Swift wasm 빌드 산출물(`.build/plugins/PackageToJS`)이 없어 `support/swift.ts`와 그 import 7건이 실패한다(Windows에서 빌드 불가).

## 검증하지 못한 것

1. 브라우저에서 세 폭의 화면과 자세히 보기 칸을 직접 보지 않았다(핸드오프대로 통합 때 확인).
2. `npm run build`와 wasm 빌드는 하지 않았다.
3. 어댑터가 새 콜백(`onArchiveOpen`·`onArchiveSelect`·`onArchiveMore`·`onSettingsOpen`·`theme`·`onThemeChange`)을 아직 잇지 않아 실제 상태로 그려 보지 않았다. `ArchiveFilter`의 TS 모양은 M 갈래와 맞춰야 한다.

## AI의 오류와 정정

1. 테스트 파일에 줄바꿈 문자열을 넣는 Python 편집이 실제 줄바꿈을 넣어 변환 오류가 났다. 정규식 `/\r?\n/`로 고쳤다.
2. 작업 폴더를 확인하지 않고 명령을 실행해 `pick-word.ts`가 레포 루트에 만들어졌다. 커밋 전에 `web/features/logged-in/`로 옮겼다.
3. 처음에는 입력줄에 초점만 있어도 하단 탭을 숨겨, 입력줄이 자동으로 초점을 받는 좁은 창에서 탭이 바로 사라졌다. 테스트에서 드러나 터치 기기에서만 숨기도록 바꿨다.
