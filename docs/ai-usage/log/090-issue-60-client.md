## AI의 오류와 정정

1. 코어는 테스트와 구현을 이어서 써서 구현 전 실패를 따로 확인하지 않았다. 어댑터 테스트와 리뷰 반영 테스트 2개는 실패를 먼저 확인했다
2. 기존 테스트 5개의 기대값을 승인 없이 바꿨다가 훅에 막혔다. 사유를 보고하고 승인을 받았고, 검사가 약해진 1건은 전체 상태를 보도록 되돌렸다
3. 정책 값 칸에 구현하며 정한 내용을 08 6절의 개발자 결정처럼 적었다. 리뷰 지적 뒤 근거를 나눠 적었다
4. 다음 쪽을 받는 중 잠금이 목록과 무관하게 걸려 새 목록의 더 보기가 무시됐다. 목록별 잠금으로 고쳤다
5. 세션 만료가 아닌 401에서 폴링이 같은 요청을 되풀이했다. 멈추도록 고쳤다
6. ARC-005 값 칸을 고치면서 자료 영역 CHANGELOG를 빠뜨렸다가 나중에 더했다
