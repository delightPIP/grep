# 2026-11-25 · 터미널 디자인 시스템과 웹 화면 시안, 문구 말투

- 이슈·PR: delightPIP/grep#5
- 커밋: 없음(커밋 전)

> **요약** AI가 터미널 컨셉 전용 디자인 시스템 "그렙 터미널"(토큰, 공통 규칙, 컴포넌트 12개)을 만들고, 그것으로 웹 화면 시안 7장(1장은 직접 쳐 볼 수 있음)을 그렸다. PO가 화면 문구를 진짜 터미널처럼 건조하게 바꾸라고 정해, 디자인 시스템·시안·명령어 설명서·PRD의 문구를 함께 바꿨다.

## 사용 도구

Claude Code(Claude Opus 5.5), claude.ai 아티팩트(Design System 유형, Design 캔버스 유형), Node.js(시안 명령 처리 로직 점검), Python(대비 계산, 문자열 치환), PowerShell·bash(영문 명령 이름 겹침 확인).

## 요청

PO: 화면 시안 작업을 하자. 터미널 컨셉 전용으로 디자인 컴포넌트와 공통 규칙을 만들어 적용하자. 어두운 기본 + 밝은 테마, 화면 여러 장 + 직접 쳐 보기. 이어서 문구를 싹 다 진짜 터미널처럼 건조하게 바꾸자(시안 + 디자인 시스템 + 문서).

## 사람의 판단

- 계정의 기존 디자인 시스템 대신 터미널 전용 시스템을 새로 만든다(PO)
- 어두운 기본 + 밝은 테마, 직접 쳐 보기 포함(PO, AI 추천 수용)
- 문구 말투: 진짜 터미널처럼 건조하게, 범위는 시안 + 디자인 시스템 + 문서(PO)

## 검증

- 글자 색 대비를 두 테마 모두 WCAG 식으로 계산(모든 글자 쌍 4.5:1 이상).
- 직접 쳐 보기 화면의 명령 처리 로직을 Node.js로 돌려 흐름 17개를 확인했다. 오타 제안이 `찻기`에 `담기`를 고르던 버그를 찾아, 한글 자모 단위 비교로 고쳤다.
- `bash Scripts/check-docs.sh`, `bash Scripts/check-stage-sensors.sh` 실행.

## 검증하지 못한 것

1. 시안과 디자인 시스템이 브라우저에서 실제로 어떻게 그려지는지(글꼴, 한글 정렬, 창 높이)는 눈으로 보지 않았다.
2. 맥 터미널에서 영문 명령 이름 겹침은 아직 확인하지 못했다.
3. 개발자 브랜치(PR #4)의 정책 COM-001 사용자 문구("이미 저장한 자료가 있어요")는 고치지 않았다. 개발자에게 바꿔 달라고 해야 한다.

## AI의 오류와 정정

1. 시안의 `최근` 기본 개수를 5건으로 만들어 명령어 설명서(10건)와 어긋났다. 문구를 바꾸면서 10건으로 맞췄다.
2. 고르기·넘기기 화면에 명령어 설명서에 없는 옵션 문법(`넘기기 --본문`)을 적었다가 지웠다.
