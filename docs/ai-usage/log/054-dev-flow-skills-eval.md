## AI 산출물

- 평가 실행: 스킬마다 서브에이전트 2개가 시나리오 3개씩, 라우팅은 서브에이전트 1개가 description만 보고 판정했다. 사용자 저장소는 빈 폴더였고, 해당 없는 단계를 시험하는 시나리오만 팀 설정 파일 하나를 넣은 폴더를 썼다. 에이전트에게 기대 행동은 알려 주지 않았다.
- 판정: 시나리오마다 기대 행동과 "하면 안 되는 것"에 대조했다.
- po-workflow-skills `d89d628`에서 고친 것
  - 공통 출력: 내용이 있는 절만 쓰고, 판단 하나를 묻는 질문에는 답부터 짧게 쓴다. 실행을 언급하면 실행 내역, 미정이 있으면 미정 절은 남긴다
  - description: `dev-flow`를 개발자 쪽 단계 판단으로 좁히고, 문서 하나의 착수 판정·티켓 분해(`dev-handoff-docs`)와 기획 빈칸 점검(`planning-gap-audit`)의 경계를 양쪽 description에 적었다
  - 평가 파일: `evals/`를 뺀 복사본으로 실행, 묶어 돌린 경우 기록, 실행 기록 표, 라우팅 행 5개와 짧은 질문 시나리오 추가
- PR #5 본문의 검증 항목을 평가 결과로 고쳤다.

- 시나리오를 한 에이전트에 3개씩 묶어 돌렸다. 시나리오마다 새 대화로 하나씩 돌린 결과와 같다고 볼 수 없다.
