# 2026-11-26 · 남은 손그림을 공통 부품으로 빼기

- 작성자: TAENI
- 이슈·PR: #25
- 커밋: 없음(커밋 전)

> **요약** 059에서 "아직 부품으로 빼지 않은 것"으로 남겨 둔 화면 안 손그림을 PO가 모두 부품으로 빼 달라고 했다. AI가 화면 파일을 다시 조회해 남은 머리줄·시트·사이드바·레일·카드·바탕·버튼을 찾았다. 그중 15개를 새 부품으로 만들고, 기존 부품 5개에 누르는 동작을 더했다. 이로써 플랫폼 부품은 27개가 됐고, 화면이 모두 그 부품을 가져다 쓰게 바꿨다.

## 사용 도구

Claude Code(Opus 5.5). 시안 캔버스(Artifact), Python 스크립트(조회, 생성, 쓰는 화면 수 계산), 내장 브라우저(렌더 확인), `Scripts/check-docs.sh`

## 요청

- 남은 것도 공통 부품으로 빼 달라.

## AI 산출물

- 기존 부품에 누르는 동작 추가: UiButton(quiet, 공유 아이콘, 개수, onPress), MTopBar(뒤로 가기), MList(누름·고르기·줄 메뉴), MSheet(누름·닫기), MCommandBar(키 동작), WSidebar(메뉴 동작)
- 새 부품 15개: MPickBar, MShareSheet, MOtherApp, MOsShareSheet, UiChoiceList, ItemDetail, ItemDetailPanel, WRail, WConsentCard, DWallpaper, DAppWindow, DMole, DMoleHover, DDropHint, DDropTarget
- 부품으로 바꾼 화면: 모바일 M1·M3·M4·M5·M6·M7~M12·I1, 데스크톱 D1~D11, 웹 09·10·24·26·28·12
- 카탈로그 갱신: C0(화면 안에 남은 것), C7(UiButton 속성), C8·C9·C10에 새 부품 카드와 조립 예시를 더함. 쓰는 화면 수를 부품 안의 부품까지 따라가 다시 셈
- [공통 컴포넌트](../../planning/components.md) 문서: 페이지 구성, 부품 목록 27개와 쓰는 화면 수, 토큰 밖 색이 모인 곳, 6절 "화면 안에 남은 것"

## 사람의 판단

- 남은 손그림도 부품으로 빼라고 정했다.
- AI가 한 화면에서만 쓰는 네 가지(M2 설명판 칸, 10 그림 칸, D5 체험 버튼, 텍스트 링크)를 화면에 두자고 제안했다. PO 확인은 아직 받지 않았다.

## 검증

- 내장 브라우저로 M3·M4·M5·M6, 10 보관함, D1, C8을 열어 부품으로 그려지는 것을 확인했다.
- 화면 파일에서 테두리·배경이 있는 버튼을 다시 찾아, 위 네 가지 말고는 남지 않은 것을 확인했다.
- `bash Scripts/check-docs.sh`: 통과

## 검증하지 못한 것

1. C9·C10 카탈로그와 D2~D11, 웹 09·24·28은 이번에 새로 열어 보지 않았다.
2. 바꾼 화면의 누르는 동작(시트 열기, 고르기, 뒤로 가기)은 그려진 모습만 확인했고 눌러 보지 않았다.
