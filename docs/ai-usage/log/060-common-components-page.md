# 2026-11-26 · 공통 컴포넌트 페이지와 플랫폼 부품

- 작성자: TAENI
- 이슈·PR: #25
- 커밋: 없음(커밋 전)

> **요약** PO가 색·글꼴·ALERT·POPUP·SHEET 같은 공통 요소를 설명이 아니라 실제 부품을 조회해 한눈에 보게 하고, 플랫폼마다 다르면 따로 지정하고, 부품 하나를 고치면 모든 화면이 바뀌게 해 달라고 했다. AI가 디자인 시스템 코드와 시안 화면 52개를 조회해 화면마다 손으로 다시 그린 부분을 찾고, 플랫폼 부품 12개를 원본 파일로 만들어 화면이 가져다 쓰게 바꿨다. 시안에 "4. 공통 컴포넌트" 페이지(카탈로그 11장)를 만들었다.

## 사용 도구

Claude Code(Opus 5.5). 시안 캔버스(Artifact), Python·Node 스크립트(조회, 생성, 구문 검사, 색 대비 계산), 내장 브라우저(렌더 확인), `Scripts/check-docs.sh`

## 요청

- 디자인 시스템을 하나로 통일하고, 컬러 테마나 ALERT·POPUP·SHEET 같은 요소를 설명만 찾지 말고 직접 공통 컴포넌트를 조회한 뒤 한 번에 볼 수 있게 만들어 달라. 플랫폼별로 지정해야 하면 따로따로 모두 지정해 달라.
- 폰트 시스템, 컬러 시스템도. 화면 시안에 "4. 공통 컴포넌트"를 더해 개발·디자이너·PO가 그것만 보고 이해하거나 수정 요청할 수 있게.
- 공통 컴포넌트의 UI가 바뀌면 전체 화면의 컴포넌트도 함께 바뀌게(유지보수).

## AI 산출물

- 조회: `bundle.js`의 부품 19개와 속성·변형, `tokens.json` 색 14개·글꼴 9가지·간격·모서리, 시안 화면 52개에서 부품 쓰임과 손으로 다시 그린 부분(휴대폰 머리줄·탭·명령 줄·시트·버튼, 데스크톱 작업 표시줄, 웹 사이드바)
- 플랫폼 부품 12개(시안 `.dc.html`): UiButton, UiCard, UiSettingRow, MTopBar, MTabBar, MCommandBar, MList, MSheet, DTaskbar, DTitleBar, DTrayMenu, WSidebar
- 화면이 부품을 가져다 쓰게 바꿈: 모바일 M1·M2·M3·M5·M6(일부)·M7~M12·I1, 데스크톱 D1~D11, 웹 12·24·26
- "4. 공통 컴포넌트" 페이지: C0 읽는 법, C1 색(대비 계산), C2 글꼴, C3 간격·아이콘, C4 터미널 출력, C5 입력·창, C6 두더지, C7 ALERT·POPUP·SHEET 플랫폼 대응표, C8 모바일, C9 데스크톱, C10 넓은 웹, 부품 원본 12장
- [공통 컴포넌트](../../planning/components.md) 문서: 고치는 규칙, 부품 목록과 쓰는 화면 수, 토큰 밖 색, 플랫폼 대응, 아직 빼지 않은 것

## 사람의 판단

- 설명이 아니라 실제 부품을 조회해서, 플랫폼별로, 한 번에 바뀌게 하라고 정했다.

## 검증

- 부품·카탈로그·바꾼 화면마다 스크립트 구문과 태그 짝을 검사했다.
- 내장 브라우저로 MSheet(부품 안의 부품), M9·M10(바꾼 화면), C0·C1, 4. 공통 컴포넌트 페이지 전체를 열어 그려지는 것을 확인했다.
- `bash Scripts/check-docs.sh`: 통과
- 전파 시험(PO 요청): `UiButton.dc.html` 한 파일만 secondary 테두리를 주황 3px로 바꿔 올렸더니, 손대지 않은 모바일 M9·M10, 데스크톱 D9, 웹 12의 버튼이 모두 주황 테두리로 바뀌었고 danger 버튼은 그대로였다. 원래 값으로 되돌려 다시 올리고 12에서 원래 모습으로 돌아온 것을 확인했다

## 검증하지 못한 것

1. 카탈로그 C2~C10은 축소 화면에서 그려진 것만 봤다.
2. 디자인 시스템 원본 아티팩트("그렙 터미널")는 고치지 않았다. 플랫폼 부품 12개는 시안 안에만 있다.

## AI의 오류와 정정

1. 모바일 생성 틀을 부품으로 바꾸며 자바스크립트 중괄호를 한 곳에서 이스케이프하지 않아 생성이 멈췄다. 고쳐 다시 만들었다.

## 발견 사항

1. 같은 캔버스를 다른 사람도 보고 있었다(접속 표시). 게시가 막히지 않았지만, 다른 작업이 그린 보관함(10, M6)의 손잡이 달린 부분은 덮어쓰지 않고 "아직 빼지 않은 것"으로 남겼다.
