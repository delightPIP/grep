> **요약** AI가 서비스를 모르는 PO 전문가용 첨삭 요청 프롬프트를 쓰고, PO가 받아 온 법률·PO 첨삭을 기존 정책과 대조해 결정할 항목을 골랐다. PO는 "진짜 프로젝트성"이라 베타·실사용자를 두지 않고 돈 안 드는 방향으로 정했다. 새 정책 4개와 수정 4개를 모두 "검토 중 (개발자 확인 대기)"로 등록했다.

## 사용 도구

Claude Code(Opus 5.5), `docs:policy-manager` 스킬, `Scripts/check-docs.sh`. 첨삭은 PO가 다른 AI 도구에서 받아 왔다.

## 요청

서비스를 모르는 PO 전문가에게 물을 설명 프롬프트를 만들어 달라는 요청. 이어서 받아 온 첨삭으로 같이 정할 정책을 골라 달라는 요청과, 프로젝트성이니 돈 안 드는 방향으로 개발자가 확인해 고칠 수 있게 써 두라는 지시.

## AI 산출물

- `docs/planning/po-expert-review-prompt.md`: 전문가 첨삭 요청 프롬프트
- 첨삭과 기존 정책 대조표(이미 정책에 있는 지적, 새로 정할 것)
- 새 정책: COM-005(무료 플랜·무료 한도 안에서만), COM-006(사용자 간 자료 격리), ARC-008(휴지통 30일), ARC-009(AI 도구 연결 반환 범위)
- 수정: COM-002(프로젝트 기간에는 팀이 만든 자료만 넣고 무료 플랜 허용), ARC-002(태그 지우기만 허용), COM-001·ARC-001(휴지통과의 관계)
- 열린 질문: 닫은 것 4개, 실사용자 전제 질문 10개를 "실제 사용자를 받기 전에 정할 것"으로 옮김

## 사람의 판단

- 운영 주체는 교육 과정 프로젝트
- 베타·실사용자 유입은 두지 않음(잠깐 초대제 베타를 골랐다가 "진짜 프로젝트성"으로 되돌림). 그래서 처리방침·약관·탈퇴·사고 대응은 정책으로 만들지 않음
- 돈이 드는 선택은 하지 않음. 값은 개발자가 확인해 고칠 수 있게 검토 중 상태로 둠
- AI 도구 연결은 요약 + 본문 텍스트까지, 원본 파일은 주지 않음
- 휴지통 30일, 태그는 지우기만 허용

## 검증

`bash Scripts/check-docs.sh` 통과.

## 검증하지 못한 것

1. 무료 플랜으로 요약·글자 읽기·세션 만료·예약 삭제가 실제로 되는지는 개발자 확인 전이다.
2. 하루 AI 처리 50건, 북마크 200건, 연결 20건·2만 자, 파일 주소 5분은 근거 없는 가정값이다.
3. 첨삭이 인용한 법령과 사례는 원문과 대조하지 않았다.
