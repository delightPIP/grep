# 2026-11-26 · PO 작업 흐름 스킬로 빈칸 점검과 결정 반영

- 작성자: @delightPIP
- 이슈·PR: #19
- 커밋: d70306b

> **요약** 이 레포의 AI 로그에서 뽑아 만든 PO 작업 흐름 스킬(po-workflow)을 그렙 문서에 적용해 빈칸, 문서 사이 충돌, PO가 확인하지 않은 AI 결정을 찾았다. PO가 데모 계정·시드·이야기·샘플·넘길 글·영문 표기·지표·삭제 방식을 정했고, AI가 정책 ARC-010을 새로 등록하고 기획 문서를 그 결정과 확정 정책에 맞췄다.

## 사용 도구

Claude Code(Claude Opus 5.5). po-workflow 플러그인의 planning-gap-audit, po-decision-gate, decision-propagation 스킬. 머지 전 브랜치의 dev-handoff-docs 스킬. docs:policy-manager. 읽기 전용 서브에이전트 셋(빈칸 점검, 착수 가능 판정, 미확인 AI 결정 수집)과 데모 시드를 다시 쓰는 서브에이전트 하나.

## 요청

PO가 스킬을 설치한 뒤 그렙에 적용해 보자고 했다. 점검 결과를 본 뒤 질문부터 답하겠다고 했다.

## AI 산출물

- 빈칸 점검표(11건), 작업 단위별 착수 판정, 문서 간 값 불일치 12건, 확정처럼 쓰였지만 PO가 확인하지 않은 AI 결정 12건과 PO 질문
- 정책: ARC-010(샘플 8건) 새로 등록, ARC-003 규칙 10 수정, ARC-008 이력에 재확인 기록, ARC-005 근거 문장 다듬기(단계 센서 오탐 해소), 자료 영역 열린 질문 하나 닫음
- 기획 문서: PRD(US-5, US-11, 10절, 4절 지표, 넘기는 내용 정의, 정책 이관 설명), 명령어 설명서(버리기, 연결, 확인 문구, 샘플), 사용자 흐름도(첫 화면, 샘플, 버리기, 외부 LLM, 같은 링크), 넘길 글 형식 상태, STATE 결정 로그 8줄과 영문 표기 설명
- 데모 시드와 발표 메모를 마케터 이야기·계정 둘·시드 30건 이상으로 다시 씀(가상 카페 브랜드, 시드 34건). 사용자 흐름도 11절 데모 경로, 넘길 글 형식 예시, 명령어 설명서·흐름도의 옛 시드 자료 제목을 새 이야기로 바꿈
- 일반 명령 예시(`찾기 결제`, `묶음 결제조사`)는 데모 이야기가 아니라 화면 예시라 그대로 둠

## 사람의 판단

- 데모 계정 둘, 시드 30건 이상, 넘길 글 형식 확정, 영문 표기 grep 확정, 발표 지표는 북극성·짝 지표만(추천안 채택)
- 데모 이야기는 추천안(결제 이야기 유지)을 고르지 않고 비개발 마케터의 캠페인 이야기로 바꿈
- 샘플 8건은 실제 아카이브에 넣고, `버리기 1-8`로 치우며, 내용은 마케터 이야기 7건과 그렙 사용법 1건
- 삭제는 처음에 "바로 영구 삭제"를 골랐다가, 같은 날 오전의 휴지통 결정과 근거를 다시 보고 휴지통 30일을 유지함
- ARC-010 등록과 ARC-003 수정안을 승인함
- 시드 자료 내용은 아직 검토 전

## 검증

- `bash Scripts/check-docs.sh` 통과
- `bash Scripts/check-stage-sensors.sh` 통과(이전에는 ARC-005 문장 오탐으로 막혀 있었음)
- 빈칸 점검과 착수 판정이 지적한 충돌은 양쪽 원문 줄을 열어 모두 확인함

## 검증하지 못한 것

- 시안(웹·모바일)과 바뀐 문구가 맞는지는 보지 않았다
- `버리기`의 번호 범위 `a-b`는 새 문법이라 개발자 확인이 필요하다
- 명령어 설명서 7절의 겹침 확인은 명령 12개 기준이고 지금 표는 13개다. 13번째 명령의 겹침은 다시 확인하지 않았다

## AI의 오류와 정정

1. 삭제 방식을 물을 때 ARC-008을 "검토 중"으로만 소개하고, 같은 날 오전 PO가 휴지통 30일을 정했다는 근거 줄을 보여 주지 않았다. PO가 영구 삭제를 고른 뒤 정책 파일을 열어 보고 알았고, 이전 결정과 근거를 함께 보여 다시 물었다. PO는 휴지통을 유지했다.
2. 명령어 설명서에 정책에 없는 문구 `! 빠진 자료 1건 (휴지통)`을 만들어 넣었다가 되돌렸다.

## 발견 사항

1. po-decision-gate 스킬에 "결정을 바꾸는 질문에는 같은 주제의 이전 결정과 근거를 함께 보여 준다"는 규칙이 없었다. 스킬 저장소에 Gotchas로 더할 후보다.
