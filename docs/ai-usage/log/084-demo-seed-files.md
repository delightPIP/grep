> **요약** 개발자가 시드 파일을 AI가 만들 수 있는지 물었고, 근거 문서와 S33(스레드 게시물) 출처를 확인한 뒤 직접 바꾸기로 정했다. AI는 demo-seed 3·4절대로 34건과 무대용 L2, `seed.json`(미리 만든 요약·태그 포함), 가상 기사 6개를 만들고 검색 낱말 규칙과 장면표 건수를 확인했다. 개발자는 S33을 비공개 문서 링크로 바꾸고 기사 공개 저장소를 정했다.

## 사용 도구

Claude Code(Opus 5.5). 스킬 `docs:ai-usage`. Python 가상환경(reportlab, python-docx, Pillow, pillow-heif, pypdf), 나눔고딕(SIL OFL), `gh`, `curl`

## 요청

- 시드 파일을 만들 수 있는지, 그렇게 만들라는 근거가 어디 있는지
- 스레드 게시물은 어디서 만들라고 했는지, 남의 계정 게시물을 쓰면 안 되는지
- 바꾼 결정을 기록하고 시드 파일 계획대로 진행

## AI 산출물

- `db/seed/demo/`: 파일 19개(PDF 5, docx 2, txt 2, md 2, 이미지 9), 붙여 넣는 글 7개, 가상 기사 HTML 6개, 무대용 L2 PDF, `seed.json`, `README.md`
- demo-seed 3·4절에 문구가 없는 16건(S03 S04 S05 S06 S08 S09 S10 S12 S14 S15 S20 S22 S24 S26 S29 S31)의 내용과 34건의 미리 만든 요약·태그 초안
- `docs/planning/demo-seed.md`: S07·S13·S19·S33 행, 2절 3번, 6절 확인 항목, 머리말, 7절 변경 기록
- `carti1108/grep-seed-demo`에 기사 6개와 목차를 올리고 GitHub Pages를 켬
