> **요약** 모바일 탭바(터미널·보관함·설정) 구상을 계기로 웹·모바일 앱·데스크톱 앱의 특성과 UI/UX 가이드라인을 디자이너·개발자·PO 역할 에이전트 셋이 나눠 조사했고, 결과를 학습 노트로 합쳤다. 정책은 아직 정하지 않았고 PO가 답할 질문을 남겼다.

## 사용 도구

Claude Code(Claude Opus 5.5), 병렬 서브에이전트 3개(디자이너·개발자·PO 역할), 웹 검색과 웹 페이지 열람.

## 요청

PO가 모바일에 탭바(홈은 지금의 터미널 화면, 아카이브를 한 번에 보는 폴더링 화면, 설정)가 필요하다고 보고, 정책을 세우기 전에 세 플랫폼의 특성과 가이드라인, 서비스를 보여 주는 방식, 기능 우선순위를 가르는 방식을 학습해 브리핑해 달라고 했다.

## AI 산출물

- [플랫폼별 UI/UX 학습 노트](../../planning/platform-ui-study.md): 가이드라인 비교, 모바일 탭 구성안 3개, 화면 세 개의 역할, 우선순위 판단 규칙, 플랫폼별 우선순위 표, 정책·ADR 후보, PO 질문

## 사람의 판단

- 아직 없음. 탭 구성, 보관함 정의, 다음 플랫폼은 PO가 정한다.

## 검증

`bash Scripts/check-docs.sh`를 실행했다. 출처는 각 에이전트가 1차 문서를 열었는지 2차 요약인지 표시했다.

## 검증하지 못한 것

1. Material 3 원문과 비교 대상 앱의 실제 화면은 보지 않았다.
2. "모바일은 저장, 데스크톱은 AI 작업" 나눔은 설문에 기기 문항이 없어 추정이다.

## AI의 오류와 정정

1. 요청한 "폴더링 화면"이 PRD 7절 제외 항목(사용자 폴더 관리 화면을 중심에 두지 않음)과 부딪힌다는 점을 짚고, 자동 묶음 보관함을 대안으로 냈다.
