### ADR-IOS-009 iOS에서 공유로 받기는 네이티브 공유 확장으로, 보내기는 시스템 공유 시트로 한다
- 상태: 제안 (개발자 확인 대기)
- 날짜: 2026-11-25
- 영역: iOS

> **요약** 다른 앱에서 그렙으로 저장하는 일은 그렙 iOS 앱 안의 공유 확장이 받는다. 확장은 받은 자료를 앱 그룹 대기열에 넣고 백그라운드 전송에 맡긴다. 그렙에서 AI 앱으로 넘기는 일은 `UIActivityViewController`로 하고 복사 버튼을 함께 둔다. 웹 앱으로는 공유를 받을 수 없으므로 모바일 단계에는 네이티브 앱이 필요하다.

#### 배경

첫 플랫폼은 웹이고 모바일 앱은 그다음이다(PRD 14절). 휴대폰에서 저장하는 주된 길은 다른 앱의 공유 시트다(US-1, US-7). 모바일 시안 M4(받기)와 M5(보내기)를 만들면서 iOS에서 어떻게 구현할지 정해야 했다. 공유 확장은 메모리와 실행 시간이 제한되고 닫히면 바로 끝난다. 그리고 공유로 무엇이 넘어오는지는 보내는 앱이 정한다.

#### 결정

1. 받기는 그렙 iOS 앱 안의 공유 확장(Share Extension)으로 한다. 받는 종류는 링크, 글, 이미지, PDF다.
2. 확장 화면은 SwiftUI로 직접 그린다. 시스템 작성 화면(`SLComposeServiceViewController`)은 쓰지 않는다.
3. 확장은 받은 자료를 앱 그룹 공용 폴더의 대기열에 넣고, 업로드는 백그라운드 `URLSession`에 맡긴다. 로그인 정보는 공용 키체인으로 앱과 함께 쓴다.
4. 본문은 보내는 앱이 글을 함께 넘길 때만 저장한다. Safari는 JavaScript 전처리 파일로 페이지 제목과 본문을 받는다. 링크만 오면 웹과 같이 "본문 못 가져옴"으로 처리한다.
5. 보내기는 `UIActivityViewController`에 넘길 글을 넣어 시스템 공유 시트를 연다. 시트 화면은 바꾸지 않는다. 같은 자리에 복사 버튼을 함께 둔다.
6. 모바일 단계에는 네이티브 iOS 앱이 필요하다. 앱은 ADR-WEB-007대로 네이티브 뷰와 carti-RIBs-Swift 공유 코어로 만들고, 공유 확장도 Swift로 만든다. 확장은 자료를 대기열에 넣기만 하고, 같은 링크 판정(COM-001)과 저장은 서버가 한다(ADR-0001).

#### 고려한 대안

| 대안 | 기각 이유 |
| :--- | :--- |
| 웹 앱(PWA) + Web Share Target으로 받기 | iOS Safari가 Web Share Target을 지원하지 않아, 그렙이 공유 시트에 나오지 않는다 |
| 공유 없이 복사 → 그렙 열기 → 붙여 넣기만 | 앱을 세 번 오가야 하고, 이미지·PDF를 받을 수 없다. 모바일 저장의 핵심 동작이 빠진다 |
| 시스템 작성 화면 `SLComposeServiceViewController` | 글 입력칸과 "게시" 버튼이 붙어 있어 "묻지 않고 저장"(F1)과 터미널 로그 모양에 맞지 않는다 |
| 확장 안에서 바로 업로드를 끝내기 | 시트가 닫히면 확장이 끝나 큰 파일이나 느린 망에서 저장이 끊긴다. 오프라인이면 잃는다 |
| 크로스 플랫폼 프레임워크의 공유 플러그인만으로 | React Native나 Flutter도 iOS 공유 확장은 따로 Swift 타깃으로 만들어야 한다. 플러그인은 이 결정의 구현 방법일 뿐이다 |
| 보내기에서 특정 AI 앱으로 바로 보내기(URL 스킴 등) | 앱마다 방식이 다르고 바뀐다. 시스템 시트가 사용자가 가진 앱을 모두 보여 준다 |

#### 결과

- 얻는 것: 휴대폰 어느 앱에서든 한 번에 저장한다. 시트가 닫히거나 오프라인이어도 저장이 이어진다. Safari에서는 로그인한 페이지 본문도 받는다. 보내기는 사용자가 가진 AI 앱 어디로든 간다.
- 비용: 웹과 별도로 iOS 네이티브 앱과 Swift 공유 확장을 만들고 유지해야 한다. 앱 그룹, 공용 키체인, 백그라운드 전송 설정이 필요하다. SNS 앱은 링크만 넘기는 경우가 많아, 로그인이 필요한 SNS 본문 문제는 공유 시트로 풀리지 않는다(스크린샷 공유와 글 붙여 넣기로 받는다). AI 앱이 공유로 텍스트를 받는지는 앱마다 달라 복사 버튼을 계속 둬야 한다.
