### ADR-BCK-008 요약은 서버 처리 워커에서 소형 LLM으로 만들고, 북마크로 가져온 자료는 처음 열거나 넘길 때 만든다
- 상태: 채택
- 날짜: 2026-11-25
- 영역: 백엔드

> **요약** 자료의 목록용 한 줄 요약과 넘기기용 요약은 서버 처리 워커가 소형 LLM으로 만든다. 북마크 가져오기로 한꺼번에 들어온 자료는 가져올 때가 아니라 처음 열거나 넘길 때 요약한다.

#### 배경

기획서 F2(요약 만들기)는 P0이고, 서비스 방향은 AI 도구에 요약을 공급하는 것이다. PO는 요약 방식을 "서버 LLM, 소형 모델"로 정했다([기획서](../../planning/PRD.md) 14절). 외부 LLM으로 보내는 범위는 정책 COM-002를 따른다.

#### 결정

1. 요약은 서버 처리 워커가 소형 LLM으로 만든다. 클라이언트는 요약을 만들지 않는다.
2. 북마크 가져오기로 들어온 자료는 처음 열거나 넘길 때 요약을 만든다. 그 전에는 제목과 출처만 보여 준다.
3. 요약에는 만든 모델과 프롬프트 버전을 함께 저장한다.
4. LLM 제공사는 ADR-BCK-003(Anthropic)을 기본으로 하고 어댑터로 바꿀 수 있게 둔다. 영상 이해(F10)를 고려한 제공사 재검토는 처리 워커 구현을 시작하기 전에 마친다.
5. 요약을 만들지 못하면 기획서 10절대로 제목과 출처만 넘긴다.

#### 고려한 대안

| 대안 | 기각 이유 |
| :--- | :--- |
| LLM 없이 메타데이터와 발췌만 넘김 | 비용은 0이지만 "AI 도구에 요약을 공급한다"는 서비스 방향과 맞지 않는다 |
| 기기 안 모델(Apple Foundation Models 등) | 웹에서 쓸 수 없고, 입력과 출력을 합쳐 4,096토큰이라 긴 자료를 다루기 어렵다 |
| 사용자가 넣은 API 키(BYOK) | API 키를 따로 만들어야 해서 입문 사용자가 이탈하고, 남의 키를 보관하는 책임이 생긴다 |
| 중형 이상 모델 | 사용자 1,000명 기준 월 약 $935로, 소형 모델(월 약 $50)의 약 20배다 |
| 북마크를 가져올 때 한꺼번에 요약 | 사용자 한 명이 1,000건을 가져오면 비용이 한 번에 몰린다 |

#### 결과

- 얻는 것: 모든 클라이언트가 같은 요약을 받는다. 비용은 백엔드 설계 문서 추정으로 사용자 100명 월 약 $5, 1,000명 월 약 $50이다.
- 비용: 자료 내용이 외부 LLM으로 나간다(COM-002). 한국어 요약 품질은 시제품에서 확인해야 한다. LLM 장애 시 요약이 늦어진다.
