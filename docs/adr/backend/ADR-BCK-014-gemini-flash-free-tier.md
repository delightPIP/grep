### ADR-BCK-014 발표까지 요약·태그·글자 읽기 LLM은 Gemini Flash 무료 등급으로 한다
- 상태: 채택
- 날짜: 2026-11-27
- 영역: 백엔드

> **요약** ADR-BCK-008 결정 4(기본 제공사 Anthropic)를 대체한다. 발표(2026-12-01)까지는 Google Gemini API의 Flash 계열 무료 등급을 쓴다. 모델 이름은 설정값(`GEMINI_MODEL`)으로 두고, 호출은 LLM 어댑터 한 곳에만 둔다.

#### 배경

COM-005는 무료 플랜만 허용한다. ADR-BCK-008 결정 4가 기본으로 둔 Anthropic API에는 무료 등급이 없다. COM-002 규칙 3은 발표까지(실제 사용자 없음) 팀 자료만 넣는 조건으로 무료 플랜을 허용한다. 처리 워커(#59) 착수 전에 제공사를 정해야 해서 #56에서 정했다.

#### 결정

1. 요약·태그·이미지 글자 읽기(ADR-BCK-005)는 Gemini API Flash 계열 무료 등급으로 한다. 키는 `GEMINI_API_KEY`, 모델은 `GEMINI_MODEL`이다.
2. 제공사 호출은 서버의 LLM 어댑터 하나에만 둔다. 제공사를 바꿔도 처리 워커는 고치지 않는다.
3. 무료 등급은 입력을 학습에 쓰고 사람이 볼 수 있으므로, 그렙 계정에는 팀이 만든 자료와 공개 자료만 넣는다(COM-002 규칙 3).
4. 실제 사용자를 받기 전에 유료(학습 미사용) 등급이나 다른 제공사로 바꾸고 이 ADR을 대체한다(COM-002 규칙 6).

#### 고려한 대안

| 대안 | 기각 이유 |
| :--- | :--- |
| Anthropic Haiku(ADR-BCK-008 기본값) | 무료 등급이 없다(COM-005) |
| Gemini 유료 등급 | 학습에 쓰지 않지만 비용이 든다(COM-005) |
| OpenAI 소형 모델 | 무료 API 등급이 없다 |
| 서버에서 로컬 모델 실행 | Render 무료 인스턴스(ADR-0011)의 메모리·CPU로는 돌리기 어렵다 |

#### 결과

- 얻는 것: 데모까지 비용이 0이다. 이미지 글자 읽기도 같은 모델로 한다.
- 비용: 입력이 Google 학습에 쓰이고 악용 감시용으로 55일 보관된다(COM-002 비고). 무료 등급의 분당·일일 한도가 시드 34건과 무대 1건을 감당하는지는 #59에서 키를 받은 뒤 실측한다.

#### 관련

ADR-BCK-008(결정 4 대체), ADR-BCK-005, ADR-0011, COM-002, COM-005, #56, #59
